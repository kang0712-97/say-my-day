# 시연 영상 대본 (2분 30초 안팎, 휴대폰 화면 녹화)
준비: 배포 주소(https://chinese-diary.onrender.com)를 미리 열어 서버를 깨워 두고(첫 접속 최대 1분), 안드로이드 화면 녹화(소리 포함), 세로. 일기는 아래 샘플을 쓰세요(개인 이야기 금지).
샘플 일기: "오늘은 아침에 비가 와서 우산을 챙겼다. 점심에는 친구와 우동을 먹었다. 저녁에는 중국어 공부를 했다."

| 시간 | 장면 | 말할 것(한 줄) |
|---|---|---|
| 0:00 | 앱 열기 → 인트로 애니메이션 | "내 하루를 외국어로 말해 보는 앱, Say My Day입니다." |
| 0:12 | 첫 화면: 새 이름 짓기(처음이면), 새와 성장 막대 | "새가 먼저 보이고, 공부하면 자랍니다." |
| 0:25 | [일기 쓰러 가기] → 날씨 고르기 → 샘플 일기 입력 → [번역하고 배우기] | "일기를 쓰면 곧바로 학습 재료가 됩니다." |
| 0:45 | 번역 중 애니메이션 → 카드 학습 시작 | "한 번에 한 가지만 보여 주는 카드입니다." |
| 0:55 | 문장 카드: 듣기·느리게 듣기, 글자 눌러 뜻 보기, [다음] | "문장을 듣고 소리 내어 따라 말합니다." |
| 1:15 | 단어 리스트: 뜻 가리기, 책갈피로 저장 | "문장에 나온 단어를 모두 모으고, 뜻을 가리고 외웁니다." |
| 1:30 | 문법 카드 → 전체 읽기 안내 → [시작] → 전체 읽기 | "마지막에 내 일기 전체를 처음부터 읽습니다." |
| 1:50 | [학습 마치기] → 오늘의 학습: 깃털 +1, 성장 막대 | "공부한 날이 깃털로 쌓이고 새가 자랍니다." |
| 2:00 | **안정성 1**: 일기 비운 채 번역 → 안내 / 중국어 글 입력 → 언어 불일치 안내 | "잘못된 입력은 호출 전에 막습니다." |
| 2:15 | **안정성 2**: 학습 도중 닫기 → [카드로 학습하기]로 이어서 열기 | "중간에 나가도 그 자리에서 이어집니다." |
| 2:25 | 일기장·일기책 한 장면 | "쓴 일기가 쌓여 나만의 책이 됩니다." |
| 2:30 | 끝(로고) | |

오류 시연(API 실패)은 실제 서버를 끄기 어려우므로 `scenes/14-err-api.js`의 화면 캡처로 대신하고 영상에는 입력 오류 2가지만 넣어도 됩니다(평가 기준: 2가지 이상 시연).
