# 폴더 연동 GPT용 지시문 v2 (복사해서 한 번에 붙여 넣기)

작업 폴더: `say-my-day/` (이 저장소 루트). 아래 경로는 모두 이 폴더 기준입니다.

## 목표
`submission/slides/발표.html` 한 파일을 만들어 주세요. **버튼과 클릭에 반응하고, 깔끔하며 완성도 높은** 16:9 HTML 발표 자료(16장 + 부록)입니다. 외부 라이브러리·CDN 없이 HTML·CSS·JS만 씁니다.

## 가장 중요한 규칙: 기준 템플릿을 그대로 쓰세요
`submission/slides/template.html`은 이미 완성된 **발표 엔진 + 컴포넌트 + 예시 장 8개**입니다(키보드·클릭·스와이프 이동, 쪽 번호, 목차 G, 대본 N, 전체화면 F, 조각 공개, 탭, 뒤집는 카드, 아코디언, 전후 슬라이더, 자라는 막대 그래프, 영상 탭, 장 바로가기 칩, 인쇄용 한 장 한 쪽).
- `발표.html`은 템플릿을 복사해 시작하고, `<style>`과 엔진 `<script>`는 **수정하지 마세요**(새 클래스가 꼭 필요할 때만 `<style>` 끝에 추가).
- `<section class="slide">` 장들만 `submission/slides-outline.md`대로 **16장 + 부록**으로 만들어 교체하세요. 장마다 `data-title`(짧은 제목)과 `data-section`(시작/서비스/설계 판단/평가/AI 활용/회고)을 넣으세요.
- 장마다 개요의 "상호작용" 칸에 적힌 컴포넌트를 쓰세요. 템플릿 예시 장의 마크업(클래스명·`data-*` 속성)을 그대로 따라 하면 됩니다: 탭(`data-tabs`/`data-tab`/`data-panel`), 조각 공개(`class="frag" data-step="1,2,…"`), 뒤집는 카드(`.flip`), 아코디언(`data-acc`), 슬라이더(`.compare`), 막대(`.bars .b`, `--w`), 영상 탭(`data-media`), 장 이동 칩(`data-goto="장 번호"`).
- 부록의 요구 대응표 칩은 개요 3절의 **새 장 번호**로 `data-goto`를 고쳐 쓰세요(템플릿 예시는 임시 번호입니다).
- 글자 크기는 템플릿 기준(무대 1920×1080 안에서 제목 64px 이상, 본문 30px 이상)을 지키고, 한 장에 상호작용은 하나만 두세요. 내용이 넘치면 줄이지 말고 조각 공개로 나누세요.

## PO 중심 + 특히 중요한 두 부분 (개요 0-1절 그대로)
- 발표 전체가 PO의 판단 기록이 되게 하세요. 1장·부록을 뺀 모든 장 아래쪽에 `PO 판단` 한 줄(결정 / 근거 / 포기한 것)을 넣으세요(템플릿의 `.bridge` 위, 작은 칩+한 줄). 근거가 없으면 "제작자 본인 사용 경험"이라고 쓰세요.
- **AI 활용 과정 기록(13~15장)** 과 **설계 문서 + 회고(6~9장, 16장)** 가 가장 중요합니다. 이 장들은 내용을 줄이지 말고 조각 공개·탭·아코디언으로 **개요에 적힌 항목을 모두** 보여 주세요(프롬프트 버전별 문제→수정→효과, CLAUDE.md 실제 규칙과 그 규칙이 막은 일, 스킬을 쓴 장면, AI 실수 6건의 발견→원인→고침→재발 방지, 맞바꾼 것의 얻음·잃음, 한계와 다음 검증). 근거는 `submission/프롬프트.md`, `CLAUDE.md`, `design/tasks/`에서 가져오세요.
