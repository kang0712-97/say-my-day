# GPT에 붙여 넣을 프롬프트 (HTML 발표 자료 제작용)
> 아래 `---` 사이를 그대로 복사하고, 이어서 `slides-outline.md`와 `metrics.json` 내용을 붙여 넣으세요. 이미지는 GPT가 볼 수 없으므로 파일명만 참조하게 했고, 만든 HTML을 `images/` 폴더와 같은 위치에 두면 됩니다.

---
당신은 발표 자료 디자이너입니다. 아래 "장별 개요"와 "수치 JSON"만 사용해, **한 개의 HTML 파일**(외부 라이브러리 없이 HTML+CSS+약간의 JS)로 16:9 슬라이드 발표 자료를 만들어 주세요.

[규칙]
1. 수치는 제공된 JSON 값만 사용합니다. 없는 수치를 만들거나 "N% 향상" 같은 표현을 지어내지 마세요. 값이 비어 있으면 "측정 전"이라고 표시합니다.
2. "사용자 테스트 결과"라는 표현은 쓰지 않습니다(하지 않았음). 평가는 "사람 없이 잰 화면 지표"라고 정확히 부릅니다.
3. 장 수는 개요의 14장 + 부록. 3번(설계 판단)·평가·AI 활용 장에 시각 비중을 더 줍니다.
4. 디자인: 흰 바탕, 잉크색 글자(#111), 회색 면(#f1f1ee), 굵고 둥근 고딕(시스템 글꼴 `-apple-system, "Apple SD Gothic Neo", "Noto Sans KR"`), 포인트 색은 쓰지 않고 선 굵기·채움(검정)으로 강조합니다. 이모지는 쓰지 않습니다.
5. 이미지는 `images/파일명`으로 `<img>`를 연결합니다(개요의 파일명 그대로). 이미지 안 글자는 가리지 말고, 폭의 40% 안팎으로 휴대폰 캡처를 나란히 배치하세요.
6. 수치 비교는 가로 막대 그래프를 CSS(div 폭 %)로 그립니다(라이브러리 금지). 값 라벨을 꼭 표시합니다.
7. 조작: ← → 키와 화면 클릭으로 장 이동, 하단에 쪽 번호(n / 전체), Home·End 지원. `@media print`에서는 장마다 한 쪽으로 인쇄(PDF 저장)되게 합니다.
8. 각 장 아래에 **발표 대본 3줄**을 `<aside class="notes">`로 넣고 화면에는 숨기되, `N` 키를 누르면 보이게 합니다. 대본은 개요의 "핵심 한 문장"과 내용만 풀어 쓰고, 새 사실을 추가하지 마세요.
9. 글자 크기는 제목 40px 이상, 본문 22px 이상(발표장에서 읽히게). 한 장에 문장 4줄·표 하나·이미지 3장을 넘기지 마세요.
10. 마지막에 확인용 체크: 사용한 수치 목록과 JSON 경로를 `<!-- -->` 주석으로 남깁니다.
