# 중국어 다이어리

한국어 일기를 초급 간체 중국어로 번역하고, 병음·발음 팁·단어·문법·활용 문장을 보여 주는 개인용 로컬 웹앱.

## 실행
```
cd app
node server.js
```
브라우저에서 http://localhost:3000 을 엽니다. 설치할 패키지는 없습니다(Node 18 이상).

## Claude API 연결
1. `app/.env.example`을 `app/.env.local`로 복사합니다.
2. `ANTHROPIC_API_KEY=` 뒤에 키를 넣습니다.
3. 서버를 다시 실행합니다. 시작 메시지에 `Claude API (모델명)`이 보이면 연결된 것입니다.

키가 없으면 목업 모드로 동작하며, 입력과 관계없이 예시 결과(`app/public/mock.json`)를 보여 줍니다.

## 자연스러운 음성 (Edge 신경망 음성, 선택)
설치하지 않으면 브라우저 음성(Google 온라인, 맥 로컬)으로 동작합니다. 설치하면 설정(⚙)의 음성 목록 맨 위에 "샤오샤오·윈시·윈양·샤오이"가 생기고 기본 선택됩니다.
```
python3 -m venv ~/.chinese-diary-venv
~/.chinese-diary-venv/bin/pip install edge-tts
```
- 마이크로소프트의 비공식 서비스라 언제든 막히거나 바뀔 수 있습니다. 막히면 음성 목록에서 다른 음성을 고르세요.
- 번역된 중국어 문장이 마이크로소프트 서버로 전송됩니다. 번역 직후 문장 음성을 미리 만들어 두므로 듣기를 누르지 않아도 문장이 전송됩니다.
- 만든 mp3는 임시 폴더(`chinese-diary-tts`)에 캐시되어 같은 문장은 다시 만들지 않습니다.
- 설치 위치를 바꾸려면 환경변수 `EDGE_TTS_BIN`에 실행 파일 경로를 지정합니다.

## 구조
| 경로 | 역할 |
|---|---|
| `prompts/system_prompt.md` | 번역·해설 규칙과 출력 JSON 형식 (현재 v0.5, 이전 버전은 `system_prompt_v0.*.md`) |
| `prompts/user_glossary.md` | 일기에 자주 나오는 이름·표현의 뜻 (우동=여자친구 등) |
| `app/server.js` | 정적 파일 서버 + `/api/translate` (Claude API 호출) |
| `app/public/index.html` | 화면. 병음은 pinyin-pro로 브라우저에서 생성 |
| `backup/` | 이전 디자인·서버 보관 |
| `data/` | 내 일기·단어·문장 저장 파일(`userdata.json`, 자동 생성, git 제외) |
| `app/public/pinyin-fix.js` | pinyin-pro가 틀리는 경성·得 교정 사전. 틀린 단어를 발견하면 여기에 추가 |
| `tests/` | 프롬프트 검증 기록. `real_*.json`은 실제 API 응답, `pinyin_check.js`는 병음 점검(`node tests/pinyin_check.js`), `review_01.md`는 독립감수 기록 |
