# 기기 확인표 (사용자가 실기기로 채운다) — 그림일기 개편 기준, 2026-10-30
칸마다 ○ / × 를 적고, ×는 한 줄로 무엇이 이상한지 적어 주세요(스크린샷이면 더 좋아요). ×가 나오면 이슈로 정리한다.

확인 방법: 앱 주소를 열고 아래 6개 화면을 차례로 본다. 글자 크기는 휴대폰 설정에서 "가장 크게"로 한 번 더 본다.
1. **쓰기** — 상단 바(로고·일기장·보관함·☰), 작은 새, 입력창(키보드가 올라와도 버튼이 가려지지 않는지), 번역하고 배우기
2. **번역 학습** — 문장 카드, 읽기 표시(병음·후리가나), 단어를 눌러 설명 패널(단어·문법·활용), 단어 저장
3. **따라 읽기** — 재생·정지, 글자 강조, 속도·문장 간격 (소리는 귀로)
4. **보관함** — 단어/문장 탭, 복습 일정, 퀴즈 한 판(정답·오답 표시가 색 없이도 구분되는지)
5. **일기장** — 달력(작성/복습), 날짜 목록
6. **설정** — 테마, 음성 고르기, 내보내기(공유 창), 전체 삭제 확인

조합별로도 한 번씩: 한국어→중국어, 한국어→일본어, 중국어→일본어 (화면 문구가 입력 언어로 나오는지, 다른 언어 글자가 섞이지 않는지).
함께 볼 것: 소리가 나는지(T13 음성 현황표), 공유 창(T14), 서버 깨우는 안내(T15), 작은 새 그림이 깨지거나 늦게 뜨지 않는지.

## 자동으로 이미 확인한 것 (`npm test` → `tests/a11y`, 2026-10-30)
- 폭 320/360/390/768/1200 × 라이트/다크 × 3개 조합 × 쓰기·결과 60화면: 글자 100%·200% 가로 넘침 0건.
- 화면에 보이는 글자 전부의 색 대비 계산(일반 4.5:1, 큰 글자 3:1): 쓰기·결과·설명 패널·통독·시트·퀴즈, 라이트·다크 모두 0건. (따라 읽기 글자 강조는 그라데이션이라 제외 — 토큰 `--ink`/`--text-subtle`는 `contrast-report.json`에서 통과.)
- 이름 없는 버튼·링크·입력 0건, `lang` 표시, 눌리는 곳 24px 이상, 장식 이미지 `alt=""`, 라디오·탭·저장 토글의 선택 상태 속성, 설명 패널 열기·닫기·Esc 후 포커스가 누른 단어로 복귀.
- **자동으로 못 보는 것(위 표로 확인):** 실제 소리, 스크린 리더 낭독, 가상 키보드가 올라온 모양, 움직임 줄이기 체감, 실기기 글꼴 렌더링.
