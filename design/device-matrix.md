# 기기 확인표 (사용자가 실기기로 채운다)
칸마다 ○ / × 를 적고, ×는 한 줄로 무엇이 이상한지 적어 주세요(스크린샷이면 더 좋아요). ×가 나오면 이슈로 정리한다.

확인 방법: 앱 주소를 열고 아래 화면을 차례로 본다. 글자 크기는 휴대폰 설정에서 "가장 크게"로 한 번 더 본다.
- 인트로 → 쓰기(일기 입력) → 결과(한자 위 읽기, 단어 누르기) → 퀴즈 한 판 → 설정(음성 고르기, 내보내기)
