# 운영 안내 한 장 (T15, 2026-10-29)

## 로그 보는 법
Render 대시보드 → 서비스 → Logs. 요청마다 한 줄 JSON: `t`(시각) `path` `status` `ms` `pair`(예: ko>zh) `chars`(글자 수) `limited`(제한 코드) `tokens`{in,out} `err`(오류 이름).
일기·문장·단어 내용과 쿼리 문자열은 기록하지 않는다. 음성·저장·언어 목록 요청은 오류(400 이상)일 때만 남는다.
- 검색 예: `"status":500`(서버 오류), `"limited"`(제한 걸림), `"/api/translate"`.
- 오류율 확인: 최근 번역 줄 중 `status`가 200이 아닌 비율. 500이 몰리면 AI 제공사 상태와 API 키 한도부터 본다.

## 사용자가 직접 해야 하는 설정 (코드 밖)
1. **비용 상한:** AI 제공사 콘솔(Anthropic 또는 Google)에서 월 지출 한도와 알림 이메일을 설정한다. 콘솔 화면 이름·위치는 바뀔 수 있어 직접 확인.
2. **가동 감시(선택):** 외부 무료 가동 감시 서비스로 5분마다 `https://chinese-diary.onrender.com/healthz`를 호출하면 잠들기 완화와 장애 이메일 알림을 함께 얻는다. `(확인 필요: 무료 플랜의 월 가동 시간 한도 안에 드는지)` — 넘으면 쓰지 않는다. 화면이 열릴 때 서버를 미리 깨우는 기능은 이미 있다.
3. **Render 알림:** 서비스 설정에서 배포 실패·중단 알림 이메일을 켠다.

## 횟수 제한 조절
Render 환경변수: `LIMIT_PER_DAY`(하루 총 번역, 기본 100), `LIMIT_PER_IP_HOUR`(1인 시간당, 기본 10). 소진되면 화면에 안내 문구가 나온다.

## 남용 방지와 한계
- 있음: 일기 글자 수 제한, 조합 검증, JSON 요청만 허용, 공개 모드에서 `Origin`이 사이트 주소와 다르면 403.
- 한계: `Origin`은 브라우저가 붙이는 값이라 서버에서 직접 보내는 요청은 막지 못한다(그 경우 IP별·하루 총량 제한이 막는다). 횟수 제한·글자 풀이 캐시·음성 파일은 메모리·임시 폴더라 재시작하면 초기화된다. 유료 플랜·디스크를 도입하면 다시 검토.
