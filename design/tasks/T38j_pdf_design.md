## 결정
- 방식은 T35 그대로(브라우저 인쇄 → "PDF로 저장", 라이브러리·서버 없음).
- 새 그림은 기존 12장만 쓴다. 나중에 교체하기 쉽게 **`PDF_ART` 한 곳**(표지 / 쪽 머리 / 마지막 쪽)에 경로만 둔다. 새 그림으로 바꾸려면 그 세 줄의 경로만 고치면 된다.
- 흑백 인쇄 기준: 글자 검정·바탕 흰색, 그림은 회색조(`filter: grayscale`), 색 글자·색 바탕 없음, 구분은 선 굵기로.

## 한 일
- **단어장·문장 목록 PDF**(`printList`): 표지 쪽(새 + 제목 + 언어 조합·개수·날짜) → 목록 쪽(쪽 머리에 새 + 제목 + 날짜). 기존 항목 구성 유지.
- **일기책 PDF**(`printBook`, 일기책 표지의 "일기책 PDF로 저장" 버튼): 표지(새 + 나의 이야기 + 쓴 날·문장·단어 수 + 기간) → 일기 한 편 = 새 쪽(쪽 머리에 새 + **날짜·요일**, "내가 쓴 일기" 원문, "문장 쌍" = 외국어 + 읽기 + 내 말) → 마지막에 새 한 마리와 "여기까지가 내 이야기예요."
- 공통: `runPrint`(그림이 로드된 뒤 인쇄), `@page` A4·쪽 번호(지원하는 브라우저에서), 문장 쌍은 쪽 중간에서 끊기지 않음, 옛날 → 최근 순으로 묶음(일기책 화면의 보기 순서와 무관).
- 문구 사전(ZH) 추가: 일기책 PDF로 저장 / 문장 쌍 / 여기까지가 내 이야기예요.

## 일기장 컨셉 점검표
① 일기장의 한 장·표지·책갈피 중 하나의 모습 — 표지 + 날짜 쪽 머리 + 왼쪽 줄 달린 문장 쌍 ✓
② 새가 함께하는 역할 — 표지·쪽 머리·마지막 쪽에 새가 있음(받아 적는/기억하는 말투 문구는 없음) △
③ 쌓인 것이 보임 — 표지에 쓴 날·문장·단어 수, 기간 ✓
