# T44a 학습 세션 L1 (카드 틀 + 문장 카드)
상태: 완료(미확인: 실제 휴대폰, 중국어 문구)。 계획: `T44_learning_flow_proposal.md`. 사용자 결정(2026-11-03): **권장안으로** = 문장 중심 루프 · 가리고 말하기 포함 · 새 단어 자동 담기 · 문법은 처음엔 끝에 모아 보기(문장별 연결은 L5).

## 한 일(L1)
- 번역이 끝나면(또는 일기장에서 "이어서 공부하기"로 열면) 전체 화면 **학습 세션**(`#learn`)이 열린다. 구성: 시작 카드 → 문장 카드(문장마다 1장) → 마무리 카드.
- 틀: 위에 × · 문장 수만큼의 진행 막대(지금 문장 강조) · `k / N` · 단계 알약 `① 문장 k/N`. 아래에 큰 [이전] [다음 문장 →](56px). 옆으로 밀기(가로 60px 이상), 키보드 ←/→/Esc, 브라우저 뒤로 가기=닫기. 움직임 줄이기면 슬라이드 없음.
- 문장 카드: 내 한국어(작게) → 외국어 문장(글자 누르면 뜻 시트) → 듣기·느리게 듣기 → "설명 보기"(T41 접기) → 힌트. 확인 필요 표시는 카드 안에 같이.
- 마무리 카드: 단어·문법 보기(전체 보기의 그 구역으로) / 일기 전체 읽기 / 공부 마치기 / 처음부터 다시. ×는 지금 쓰는 긴 목록 화면("전체 보기")을 그대로 보여 줌. 번역 결과 화면 맨 위에 "카드로 학습하기" 버튼도 추가.
- 자리 저장: `learn-pos`(문장 묶음 키 + 카드 번호). 새로 번역한 직후는 처음부터, 일기장에서 다시 열면 닫은 자리부터.
- 시험: 스모크(카드 수=문장+2, 문장 카드 내용, 닫기·이어 열기, 마무리 카드)와 접근성(3개 조합·폭 5종·라이트/다크, 글자 200%)에 학습 화면 추가.

## 알려진 것
- **중요: 따라 말하기(마이크)는 지금 꺼져 있다(`SPEAK_ON=false`, 2026-11-02 사용자 요청).** 제안서의 ② 따라 말하기·⑤ 가리고 말하기는 마이크 없이 "소리 내어 말했어요"/"기억났어요 · 한 번 더" 버튼으로 먼저 만들고, 마이크는 나중에 켜면 붙는 구조로 L2·L3를 만든다.
- 아직 없는 것(L2~): 단어 카드·문법 카드·말하기·가리고 말하기·새 단어 자동 담기, 새 자세 연동. 지금은 단어·문법을 전체 보기에서 이어서 본다.
