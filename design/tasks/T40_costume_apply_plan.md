## 이미지 검토 결과
- 97개 PNG(1254×1254, 장당 약 0.8MB, 전체 약 75MB). 성장 10단계(G01–G10) 복장 구분이 분명하고(턱받이·노란 모자·가방·둥근 안경·재킷·졸업모·셔츠·베레모) 단계 안에서 얼굴·비율이 유지된다. 흑백 + 노랑 한 점이라 인쇄·다크 모드에도 유리.
- 알(G01·G02)은 동작이 없고 master 1장뿐. G03~G10은 쓰기·듣기·따라읽기·복습·완료·스티커·휴식·인사 8동작.
- special 23장 중 21장이 **G09(어른새) 전용**이라 다른 단계에서는 못 쓴다(F04는 G03 전용, T01/T02는 부화 전환 전용, T05·P01은 G10 전용). 실제로 모든 단계에서 쓸 수 있는 건 단계별 8동작 + master.
- 정지 이미지라 "움직임"은 CSS로 만든다(숨쉬기·통통·갸웃·흔들림).
- 용량: PNG 그대로는 못 쓴다. 현재 단계의 8동작만 360px 정도 webp로 변환(장당 20~40KB 예상)해 쓰고, 나머지 단계는 필요할 때만 불러온다.

## 더 필요한 이미지 (G03~G10, 8단계)
- 필수 16장: **생각 중(think)** 8, **앗·다시(oops)** 8. 번역 대기·오류 화면에 지금은 대체할 그림이 없다.
- 있으면 좋은 16장: **간지러워 웃음(giggle)** 8, **깜짝(surprised)** 8 — 새를 만졌을 때 반응용. 없으면 welcome/complete/rest를 돌려 쓰고 CSS 움직임으로 때운다.
- 알(G01·G02) 반응은 그림 추가 없이 흔들림 + "톡톡" 문구로 처리.

## 첫 화면 제안: "내 새" 화면을 첫 화면으로 (별도 페이지 아님)
위에서 아래로: 상단 바 → 새(약 200px, 둥지/종이 받침 위, 터치 가능) → "초등학생새 · 12일째" → 말풍선(새가 하는 말 한 줄) → 성장 막대 "다음 성장까지 N일" → 쌓인 것 보드(쓴 날·일기·문장·단어, 이번 주 7칸) → 아래 고정 버튼 "일기 쓰러 가기".
- 쓰기 화면(T39 일기 양식)은 버튼을 누르면 가는 다음 화면. 로고/뒤로가기로 돌아온다.
- 오늘 이미 썼으면 버튼이 "오늘 한 편 더 쓰기"와 "복습하기"로 바뀐다(압박 문구 없음).

## 터치 반응·말하기
- 탭: 통통 튀고 동작 그림이 바뀐다(welcome → complete → rest 윙크 …) + 말풍선이 바뀐다. 5번 이상 빠르게 누르면 "간지러워요".
- 길게 누름: 눈 감는 그림(rest) + 조용한 한마디.
- 가만히 있을 때: 천천히 숨 쉬듯 커졌다 작아짐. 가끔 한 번 통통.
- 말 내용: 앱 안의 문구 모음(단계별 × 상황별: 처음 방문·오늘 썼음·오랜만·성장 직전·밤). AI 호출 없음(크레딧 안 씀, 오프라인 가능). 해명·압박 문구 금지.
- 접근성: `prefers-reduced-motion`이면 움직임 없이 그림·말만 바뀜. 새 그림은 장식(alt 빈 값), 말풍선은 읽히는 글자. 새는 `button`이라 키보드·스크린리더로도 누를 수 있음.

## 작업 순서(카드 단위, 각각 백업·`npm test`·README·로컬 커밋)
1. **T40a** 변환·교체 기반: webp 변환(공통 여백으로 맞춤), `birdArt(pose)`(현재 단계 기준) 도입, 기존 `bird(name)`·성장 단계 그림을 새 그림으로 교체. 전 화면 자동 반영.
2. **T40b** "내 새" 첫 화면: 위 구성, 쓰기 화면과 분리, 하단 고정 버튼.
3. **T40c** 터치 반응·말풍선·숨쉬기.
4. **T40d** 나머지 적용: PDF 표지·쪽 머리(`PDF_ART`), 성장 순간(master→complete), 책갈피·공유 틀.
5. **T40e** 추가 이미지(think·oops 등)가 오면 연결.
- 보류(정책 미정): 깃털 스티커 나무·배지·성장 기준 일수. 이미지 패키지도 확정하지 않았다고 적혀 있어 지금 적용하지 않는다.

## 사용자가 정해 줄 것
1. 첫 화면을 "내 새"로 바꿔도 되는가 (쓰러 가는 데 한 번 더 누름).
2. 성장 단계 일수(지금 0·1·3·7·14·24·36·50·70·100일)를 그대로 쓸지.
3. 새 이름 짓기(사용자가 새에게 이름을 붙임)를 넣을지 — 애착용 기능, 이번엔 선택 사항.
