# T39 그림일기 한 장 양식(쓰기 화면 + 일기책 쪽)
상태: 1차 완료(미확인: 휴대폰 화면, 중국어 문구). 사용자 요청 2026-11-02: "진짜 일기장 같은 느낌"(그림일기 양식 사진 3장 참고)
결정(사용자 선택): 적용 범위 = 쓰기 화면 + 일기책 쪽, 글 쓰는 영역 = 가로줄 노트

## 한 일
- 쓰기 화면을 그림일기 한 장으로: ① **머리 칸**(굵은 테두리) 날짜·요일·언어 / **오늘의 날씨**(맑음·흐림·비·눈, 켜고 끄는 버튼, 안 골라도 됨) ② **그림 칸**(굵은 테두리) 새 + 새 말풍선 + 새 단계 ③ **가로줄 쓰기 칸**
- 고른 날씨는 그날 쓰는 일기에 붙어(`weather`) 일기책 쪽 머리의 날짜 옆에 아이콘으로 보인다
- 문구 사전(ZH) 추가: 오늘의 날씨·맑음·흐림·비·눈
## 일기장 컨셉 점검표
① 일기장의 한 장(머리 칸·그림 칸·줄 칸) ✓ ② 새가 그림 칸에서 함께 씀 ✓ ③ 쌓인 것(단계 표시가 그림 칸 안) ✓
