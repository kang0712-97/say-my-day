# T38g 일기책 쪽 구조 + 핵심 단어 예문 접기
상태: 완료(미확인: 휴대폰 화면·소리·마이크, 중국어 문구). 넘기기 드래그는 2026-11-02 추가(아래 추가 참고)
## 한 일 (2026-11-02 사용자 요청)
- 일기책 쪽 = 일기 1편 1쪽(6문장 분할 폐지): 날짜 → **내가 쓴 일기(입력 언어 원문)** → **번역한 일기(출력 언어 전체)** → [한 문장씩 읽어보기] [이 일기 다시 공부하기]
- "한 문장씩 읽어보기"를 누르면 같은 쪽 아래에 문장 카드가 펼쳐져 듣기·따라 말하기·가리고 말하기로 공부. "이 일기 다시 공부하기"는 일기책을 닫고 단어부터 이어지는 학습 화면(`openEntry`)으로 이동
- 보기 순서(최근·옛날·무작위)는 책 안, 책 제목 "내 일기장"(T38f 보완)
- "새 한마디"(버튼·말풍선) 삭제(사용자 요청)
- 핵심 단어 카드는 단어·발음·뜻·듣기·저장만 보이고, 활용 문장은 "예문 보기" 버튼으로 눌러 펼침(`data-lcex`, 접기 요소 `<details>` 아님)
## 일기장 컨셉 점검표
① 일기장 한 장(날짜 책갈피·줄 종이) ✓ ② 새는 표지에서 책을 안고 있음, 쪽 안의 새 말은 삭제 △ ③ 내가 쓴 글과 번역이 한 쪽에 쌓여 보임 ✓
