# T45 학습 세션 개편 (2026-11-03 사용자 요청)
상태: 1차 완료(미확인: 휴대폰, 중국어 문구). 2차(로고·인트로)는 `T46`.
- **저장 표시는 책갈피**: 별 아이콘을 책갈피(안 채움/채움)로 모두 교체(`ICON.star/starFill`이 책갈피를 그림). 문구 "별 버튼"→"책갈피 버튼"(한·중).
- **버튼 글자**: 문장 카드의 "소리 내어 말했어요" → **"다음"**. 시작 카드 "시작하기", 전체 읽기 안내 카드 "시작".
- **순서**: 시작 → 문장마다(듣고 말하기) → 단어 리스트 → **문법 카드**(문법마다 1장) → **활용 문장 1장**(문법 뒤에 같이) → "이제 전체 문장을 읽어볼게요"(버튼 없음, 아래 "시작"만) → 전체 읽기 → 학습 통계. 위쪽 알약 번호는 있는 단계만 ①②③④로 매김.
- **전체 읽기 페이지**를 학습의 연장으로 다시 디자인: 같은 위쪽 막대(진행 막대 전부 채움)·알약("④ 전체 읽기"), 조작 막대는 **불투명**(문장 듣기 버튼이 비쳐 보이던 것 수정, 쌓임 순서 위로), 문장 칸 폭·여백 축소(마이크 없을 땐 오른쪽 여백도 줄임), 속도는 **느리게·보통만**, 쉬는 시간 조절·병음/한국어 체크·복사 단추 제거, 아래 "학습 마치기".
- **학습 통계 페이지**(`openFinish` 재구성): 날짜 · "오늘의 학습" · 새 · 문장/단어/분 · **깃털 상자**(깃털이 떨어지며 "깃털 +1" → 성장 막대가 이전 칸에서 새 칸까지 채워짐 → "다음 성장까지 N일", 단계가 오르면 막대가 가득 차고 성장 연출) · 응원 · 홈으로(첫 화면으로)/퀴즈. 오늘 이미 깃털을 받았으면 "오늘 깃털은 이미 받았어요"로 움직임 없이. 움직임 줄이기면 즉시 최종 상태.
- **위쪽 일기장·보관함**: 그림 아이콘을 글자 위에 둠(일기장=쪽 달린 책, 보관함=스크랩 보드), 배지는 아이콘 모서리.
- 시험: 스모크·접근성에 새 순서, 마지막 카드 버튼 하나, 시작→전체 읽기→학습 마치기→통계→홈으로, 조작 막대 불투명, 속도 2개 포함. 시험은 API를 쓰지 않음.
- 해석 메모: "문법하고 활용문장은 따로 하지 말고"는 활용 문장을 문법 단계 안에 함께 두는 것으로 해석(문법 카드 뒤 1장). 다르면 알려 주세요.
