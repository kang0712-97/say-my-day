# T24 보관함·복습·퀴즈
상태: 완료(미확인: 휴대폰 화면·소리·중국어 문구)
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '보관함과 복습', 보드 04(왼쪽), `design/tasks/T10b`·`T10c`

## 할 일
1. 보관함: '단어/문장' 분할, '오늘 복습할 N개'+복습 시작, 목록 행(글자·읽기·뜻·듣기·더보기). 삭제는 보조 메뉴(더보기)로, 듣기는 가까이. 복습할 것이 없으면 `12-rest-no-review`+문구. 헤더 `08-review` 96px.
2. 복습 일정(`due`, `dueLabel`, 오늘의 복습)은 로직을 바꾸지 않고 표시만 새 스타일.
3. 퀴즈(시안 없음 → 규칙에서 파생): 모든 종류(뜻 고르기, 글자 보고 쓰기, 순서 맞추기, 문장 등)를 새 컴포넌트(캡슐·44px·반경 12/18)로. 정오는 아이콘+문구+형태(색만 금지). 보드의 '복습 상태 예시'는 별도 상태이지 목록 아래 퀴즈 동시 표시가 아니다. 새 화면이 막히면 시안을 사용자에게 요청.

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F6·F7. 오늘 복습 개수 계산, 정답/오답에 따른 다음 일정, 단어·문장 구분, 일본어 히라가나 입력 퀴즈.

## 완료 기준
- 퀴즈 전 종류가 3조합에서 끝까지 동작(스모크 16회), 정오 상태가 색 없이도 구분됨.
- 복습 일정 결과가 개편 전 코드와 동일(같은 입력 → 같은 `due` 값 비교).
- 삭제는 더보기 안에서만, 삭제 확인에 대상 표시.
- 빈 상태(복습 없음, 저장 없음) 문구+이미지.

## 검증 방법
`npm test` 통과(분리 서버), 라이트·다크 × ko>zh·ko>ja·zh>ja × 폭 360/390 스크린샷을 해당 보드와 나란히 비교, 글자 200% 가로 넘침 0, 사용한 색 쌍을 `contrast-check`로 재계산. 소리·실기기는 "미확인"으로 적고 사용자에게 요청.
추가: 개편 전 백업과 같은 시나리오로 `dueLabel` 결과 비교 스크립트.

## 결과
보관함을 '보관함·복습' 머리글(08 새 96px)+단어/문장 캡슐 탭+오늘 복습 카드(개수·복습 시작 56px)+행(글자·읽기·뜻·복습 상태·듣기 44px·⋯)으로 개편. 삭제는 ⋯ 안에서만, 확인 문구에 대상 표시. 복습 없음=12 새, 저장 없음=09 새(머리 그림 교체로 새는 한 마리). 퀴즈 전 종류를 새 컴포넌트로(보기 56px·반경 12, 정오=아이콘+정답/오답 글자+실선/점선 테두리, 피드백 상자도 아이콘+글자+형태). 복습 일정 코드(applySrs·dueLabel·INTERVALS)는 변경 없음: 개편 전 백업과 80개 시나리오 비교 동일(tests/due_compare.js). 퀴즈 16회 스모크·접근성(글자 200% 넘침 0)·i18n 키 통과, 색 쌍 대비 전부 통과(최저 6.15:1). 부수 수정: 보기 버튼 중국어/일본어 글자의 lang 속성이 문자 그대로 출력되던 버그, 일본어 읽기 덩어리(.rg)가 글자와 겹치던 것. 백업 backup/index_vault_v39.html. 미확인: 휴대폰 화면·소리·ZH 문구 검수.
