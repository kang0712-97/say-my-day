# T24 보관함·복습·퀴즈
상태: 대기
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '보관함과 복습', 보드 04(왼쪽), `design/tasks/T10b`·`T10c`

## 할 일
1. 보관함: '단어/문장' 분할, '오늘 복습할 N개'+복습 시작, 목록 행(글자·읽기·뜻·듣기·더보기). 삭제는 보조 메뉴(더보기)로, 듣기는 가까이. 복습할 것이 없으면 `12-rest-no-review`+문구. 헤더 `08-review` 96px.
2. 복습 일정(`due`, `dueLabel`, 오늘의 복습)은 로직을 바꾸지 않고 표시만 새 스타일.
3. 퀴즈(시안 없음 → 규칙에서 파생): 모든 종류(뜻 고르기, 글자 보고 쓰기, 순서 맞추기, 문장 등)를 새 컴포넌트(캡슐·44px·반경 12/18)로. 정오는 아이콘+문구+형태(색만 금지). 보드의 '복습 상태 예시'는 별도 상태이지 목록 아래 퀴즈 동시 표시가 아니다. 새 화면이 막히면 시안을 사용자에게 요청.

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F6·F7. 오늘 복습 개수 계산, 정답/오답에 따른 다음 일정, 단어·문장 구분, 일본어 히라가나 입력 퀴즈.

## 완료 기준
- 퀴즈 전 종류가 3조합에서 끝까지 동작(스모크 16회), 정오 상태가 색 없이도 구분됨.
- 복습 일정 결과가 개편 전 코드와 동일(같은 입력 → 같은 `due` 값 비교).
- 삭제는 더보기 안에서만, 삭제 확인에 대상 표시.
- 빈 상태(복습 없음, 저장 없음) 문구+이미지.
