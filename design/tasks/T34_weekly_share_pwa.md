# T34 주간 돌아보기(말한 개수 포함)·공유 카드·홈 화면 설치
상태: 셋으로 쪼갬(2026-11-02). T34a=1번(완료), T34b=2번, T34c=3번(완료, 4번은 후순위)
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 주간 돌아보기: 이번 주 새로 익힌 단어 수, 가장 자주 쓴 표현, **말해 본 단어 수·문장 수**(T32 기록)를 카드 한 장으로. 일요일 또는 홈에서 언제든 열기. 또 설정/보관함 쪽에 누적 "말한 단어 N개 · 문장 N개"를 한 줄 표시.
2. 공유 카드: 오늘의 일기 한 문장+번역+새 그림을 이미지로 저장·공유(공유 창은 T14 방식 재사용). 개인 정보가 들어가므로 공유 전 미리보기 확인.
3. 홈 화면에 설치(PWA): 매니페스트·아이콘·오프라인 최소 동작. 푸시 알림은 하지 않는다.
4. (후순위 메모) "작년 오늘/한 달 전 오늘".

## 반드시 유지할 기능
F9(저장·내보내기), F12, F13. 서버 비용 늘리지 않기.

## 완료 기준·검증
스모크, 공유 이미지 생성 시험, 매니페스트 검사. 실기기 설치·공유 창은 사용자.
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.
