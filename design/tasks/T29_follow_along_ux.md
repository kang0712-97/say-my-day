# T29 따라 읽기 UX: 속도·간격 칩, 흐르는 강조, 단어·문법·활용 이어서 보기
상태: 대기
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 속도 칩(느리게/보통/빠르게)을 따라 읽기·결과 화면에 바로 노출, 선택 기억. 설정에는 세부 조절만.
2. 문장 사이 간격 선택지: 없음/0.5초/1초/2초, 기본 1초. 속도 칩 옆에서 바로 변경.
3. 글자 강조를 "글자별 색 전환"에서 문장 위로 부드럽게 흐르는 채움(와이프)으로. 글자별 시간표(`charTimes`) 재사용. 아래쪽에서 한 글자씩 끊겨 넘어가는 영역(병음 줄 등)은 같은 흐름으로 맞추거나 제거(먼저 어느 요소인지 `grep`으로 확인하고 사용자에게 알린다).
4. 하단 설명 패널(단어/문법/활용 탭) 폐지 → 문장 카드 아래로 이어서 단어 → 문법 → 활용 문장이 쭉 나열. 항목 누르면 그 자리에서 펼침(아코디언). 옛 나열 형식(백업 `backup/index_*`에서 참고)이 사용자에게 더 좋았음.

## 반드시 유지할 기능
F4, F5, F3, F13. 단어 저장(F6), 단어 누르기, 글자 강조 시간 맞음, 키보드/스크린 리더(패널 포커스 시험은 아코디언으로 갱신).

## 완료 기준·검증
분리 서버 스모크·a11y 시험 갱신 후 `npm test` 통과, 3조합 스크린샷, 강조 흐름은 `tests/browser_check.js`. 소리·체감은 사용자.
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.
