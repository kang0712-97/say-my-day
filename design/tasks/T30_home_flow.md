# T30 홈 흐름 재설계: 번역한 일기는 "이어서 공부하기"
상태: 대기
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 번역이 끝난 오늘 일기는 홈에서 카드로(한 줄 미리보기 + 큰 버튼 "이어서 공부하기"). 쓰기 칸은 "＋ 새 일기 쓰기"를 눌렀을 때만 열기.
2. 이미 쓴 일기를 고치면 버튼 이름 "수정해서 다시 번역"(처음 번역과 구분). 번역 없이 같은 글이면 다시 번역하지 않고 공부 화면으로.
3. 홈 위쪽 순서: ① 이어서 공부하기 ② 오늘의 복습 ③ 새 일기 쓰기 (하루 흐름 순).
4. 결과 화면에서 뒤로(←) 가면 홈으로. 일기장에서 날짜를 누르면 번역 재호출 없이 바로 학습 화면.
5. "방금 번역 보기" 링크 폐지(카드로 대체).

## 반드시 유지할 기능
F8, F11(번역 중 중복 제출 방지), F1, F12. 데이터는 건드리지 않는다(F9).
