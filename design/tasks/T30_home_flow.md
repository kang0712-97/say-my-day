# T30 홈 흐름 재설계: 번역한 일기는 "이어서 공부하기"
상태: 쪼갬 — T30a(할 일 1~5) 완료, T30b(할 일 4-1 일기장 날짜별 보기) 완료. 규칙 5(2026-10-30)
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 번역이 끝난 오늘 일기는 홈에서 카드로(한 줄 미리보기 + 큰 버튼 "이어서 공부하기"). 쓰기 칸은 "＋ 새 일기 쓰기"를 눌렀을 때만 열기.
2. 이미 쓴 일기를 고치면 버튼 이름 "수정해서 다시 번역"(처음 번역과 구분). 번역 없이 같은 글이면 다시 번역하지 않고 공부 화면으로.
3. 홈 위쪽 순서: ① 이어서 공부하기 ② 오늘의 복습 ③ 새 일기 쓰기 (하루 흐름 순).
4. 결과 화면에서 뒤로(←) 가면 홈으로.
4-1. **일기장 달력에서 날짜를 누르면 그 날짜의 일기만 달력 아래에 나열**(그 달 전체 목록이 아니라 선택한 날짜 것만; 선택한 날짜는 달력에서 표시). 같은 날 여러 편이면 모두. 일기가 없는 날은 빈 상태 문구(ko/zh) + "이 날 일기 쓰기". 항목을 누르면 번역 재호출 없이 바로 학습 화면. 기본 선택은 오늘, 선택 해제하면 달별 목록.
5. "방금 번역 보기" 링크 폐지(카드로 대체).

## 반드시 유지할 기능
F8, F11(번역 중 중복 제출 방지), F1, F12. 데이터는 건드리지 않는다(F9).

## 완료 기준·검증
스모크에 "번역 후 뒤로 → 홈에 카드, 쓰기 칸 닫힘" 추가, `npm test` 통과, 360/390 스크린샷.
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.

## 결과
**T30a(완료):** 오늘 번역한 일기가 있으면 홈 위에서부터 "이어서 공부하기" 카드(미리보기+큰 버튼) → 오늘의 복습 → "새 일기 쓰기" 순, 쓰기 칸은 새 일기 쓰기를 눌러야 열림(`syncHome`·`openNewDiary`). 고친 글은 "수정해서 다시 번역"(번역하면 옛 일기를 바꿈, 새 편으로 쌓지 않음), 고치지 않은 같은 글은 번역 호출 0회로 공부 화면(`openEntry`). "방금 번역 보기" 제거. 결과에서 뒤로는 이미 홈. 스모크에 홈 카드 시나리오 추가(3조합), `npm test` 7단계 통과, 동작 시험(같은 글 calls=0, 라벨 3종), 360px 스크린샷 확인. 미확인: 휴대폰 화면·중국어 문구. 백업 `backup/index_홈전_v47.html`.
**T30b(완료):** 달력 날짜가 버튼(`data-day`, `aria-pressed`)이 되어 누르면 그 날짜 일기만 달력 아래에 나열(같은 날 여러 편이면 모두, 시간순). 기본 선택은 오늘, 같은 날을 다시 누르면 해제되어 그 달 전체 목록, 달을 넘기면 해제. 일기 없는 날은 빈 문구, **오늘일 때만** "이 날 일기 쓰기" 버튼(지난 날짜로 쓰면 날짜·연속 기록이 어긋나 막음 — 필요하면 결정 요청). 항목을 누르면 번역 없이 학습 화면. 스모크에 시나리오 추가, `npm test` 7단계 통과, 360px 스크린샷 확인. 미확인: 휴대폰 화면·중국어 문구. 백업 `backup/index_날짜별전_v48.html`.
