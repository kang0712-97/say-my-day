# T33 3분 복습 + 작은 새 성장
상태: 둘로 쪼갬(2026-11-01). T33a = 1번 + 마무리 화면(새는 기존 그림 임시), T33b = 2·3번 + 깃털·꾸미기(제안·결정 후)
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 홈에 "3분 복습": 오늘 복습할 단어 5개 + 예시 문장 듣기(T31). 일기 없이도 들어올 이유. 끝나면 짧은 마무리 화면.
2. 복습한 단어 수에 따라 새가 자라는 단계(연속 일수 압박 없이). 단계 기준과 이름은 시작 때 사용자에게 확인.
3. 새 이미지 단계 N장 필요(사용자가 만든다). 없으면 기존 12장으로 임시 대체하고 교체 자리를 표시.

## 반드시 유지할 기능
F7, F8, F12. 복습 일정(`due`) 계산 규칙은 바꾸지 않는다.

## 완료 기준·검증
일정 값 비교, 스모크, 스크린샷. 이미지 파일은 WebP·크기 예산(`design-system-final-2026-10-29/DESIGN.md`) 준수.
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.

## 결과
T33a(2026-11-02): 홈 "3분 복습" 카드(새 그림 08-review 임시+새 말 `BIRD_SAY`, 복습할 단어 수 또는 "가볍게 훑어봐요") → 복습할 차례 단어 5개(모자라면 곧 차례인 단어로 채움)를 기존 퀴즈 엔진으로 진행, 끝나면 새 말+"단어 N개를 복습했어요" 마무리. 새 단어 카드에 "예문 듣기" 추가(정답 화면은 T31). 복습 일정 계산 불변(분리 서버에서 box·due 확인), `npm test` 전부 통과. 단어가 있으면 홈의 "복습할 것 N개" 링크는 숨김(문장만 남았을 때만 표시). 미확인: 휴대폰 화면·소리, 중국어 문구, 새 말 문구. T33b(새 성장·깃털)는 별도.

## 2026-11-01 사용자 결정·요청 (T33b 근거)
- 단계: 알 → 아기 짹 → 어린이 짹 → 청년 짹 → 어른 짹 (5단계). 언어 조합(ko>zh 등)마다 처음부터.
- 기준: 복습한 단어 수가 아니라 **일기 학습 일수**. 연속으로 하면 깃털을 더 얻고, 깃털로 새를 꾸민다. 연속이 끊기면 얻는 깃털이 적어진다(벌칙·압박 문구 없이).
- 순서: 짧게 되는 것(T33a)부터. T33b는 구체안을 제안해 결정한 뒤 이미지 프롬프트를 주고, 사용자가 GPT로 이미지를 만든다. 그때까지 기존 12장으로 임시 대체.

## 2026-11-01 T33b 결정 (사용자 승인)
- 학습한 날 = 일기 번역·공부 또는 3분 복습을 마친 날(하루 1회로 침). 언어 조합별로 따로 셈, 브라우저 저장 + 백업 파일에 포함.
- 단계 경계(일수): 알 0~5 → 아기 5~15 → 어린이 15~50 → 청년 50~100 → 어른 100~200(200일에 완성). 내려가지 않음. (해석 확인 필요: 숫자를 "그 단계가 끝나는 날"로 읽음)
- 깃털: 기본 1/일, 연속 2일째부터 2, 연속 7일 이상 3, 끊기면 다시 1. 벌칙·끊김 알림 없음.
- 꾸미기: 소품 6~8종(3~10깃털), 새 위에 겹치는 투명 PNG, 단계 이미지는 기본 모습. 입혔을 때 자연스럽게 맞는 것이 핵심(소품은 단계별 머리·목 위치 기준을 맞춰 제작).
- 나중에: 로딩 페이지에 애니메이션 또는 이미지 몇 장 이어지는 동작.
- 새의 재잘거리는 말(귀엽고 재치 있는 말투 "~짹"): 홈·복습 마무리 등에 무작위로. 예) 왜 이제 왔어 기다렸잖짹 / 오늘은 무슨 일이 있었짹? / 보고 싶었짹 / 나중에 내 언어도 배워서 나랑 얘기하짹. 상황별(오랜만, 복습 끝, 연속 중 등) 문구 목록은 T33a에서 시작, 언어별 번역은 `T`/`L()` 방식.
- 새 말 문구 목록은 `design/bird-lines.md`에 저장(승인됨). 더 다채롭게 늘리는 일은 나중 과제.
