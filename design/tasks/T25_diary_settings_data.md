# T25 일기장·설정·데이터
상태: 대기
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '일기장·설정과 데이터', 보드 04(가운데·오른쪽), `design/tasks/T12`·`T14`

## 할 일
1. 일기장: 월 달력(작성한 날/복습한 날을 모양과 범례로 구분), '새 일기', 날짜 목록(날짜·첫 문장·더보기). 빈 날짜는 첫 기록 안내(`09-first-entry`), 연속 기록을 압박하는 문구 금지. 300개 상한 안내 유지.
2. 설정 3그룹: '언어와 읽기'(번역 언어, 테마 자동/라이트/다크, 병음 보기, 음성·속도), '내 표현 사전'(상세에서 편집), '데이터'.
3. 데이터: 일기는 브라우저에 저장되지만 번역 때 입력문이, 음성 때 번역문이 외부 서비스에 전달됨을 구분해 설명. 내보내기·백업 불러오기와 전체 삭제를 분리, 전체 삭제는 별도 확인에서 대상과 영향 설명. 백업 알림·저장 정보 유지. 설정·삭제 확인에는 새를 쓰지 않는다.
4. 시트 → 뒤로 가기가 있는 전체 페이지 방식으로 바꾸는 방법을 정한다(`openSheet` 이름은 유지해도 됨).

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F8·F9·F10. 내보내기 스키마·공유 시트, 불러오기 병합(300 상한), 전체 삭제 서버 호출(`/api/data/clear`), 서버 동기화, `localStorage.clear` 후 재시작.

## 완료 기준
- T12·T14의 시험(지우기 후 키 0개, 내보내기→불러오기 왕복 개수 일치, 마이그레이션)을 새 화면에서 다시 통과.
- 삭제 확인에 무엇이 지워지는지 문구, 취소 가능.
- 일기장 달력의 두 상태가 색 없이도 구분.
- 표현 사전 추가·수정·삭제 동작.
