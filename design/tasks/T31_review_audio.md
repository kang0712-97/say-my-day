# T31 복습에서 단어·예시 문장 듣기
상태: 완료
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 보관함 단어 카드와 퀴즈 정답 화면에 🔊 버튼: 단어, 예시 문장 각각 재생. 기존 음성 기능(`speakSegment` 등)과 폴백 재사용.
2. 재생 중 정지, 퀴즈 진행을 막지 않기. 예시 문장이 여러 개면 목록에서 각각.

## 반드시 유지할 기능
F4, F6, F7. 퀴즈 정오 표시·복습 일정 값이 바뀌지 않아야 함.

## 완료 기준·검증
스모크 퀴즈 16회 통과, 음성 폴백(기기 음성) 브라우저 시험. 실제 소리는 사용자.
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.

## 결과
보관함 단어 카드에 예시 문장 줄+🔊(`.vex`), 퀴즈 정답 화면에 단어 카드면 "예문 듣기" 추가(단어·문장 듣기는 이미 있었음). 기존 `speak` 재사용이라 기기 음성 폴백 그대로. 분리 서버 브라우저 시험: 예문 버튼 1개 생성·재생·정지 동작, 단어장 값 불변. `npm test` 7단계 통과(스모크 퀴즈 포함). 미확인: 실제 소리, 휴대폰 화면 폭, 퀴즈 정답 화면의 예문 버튼 직접 클릭(스모크는 통과), 중국어 문구(기존 키 `예문 듣기` 재사용). 백업 `backup/index_복습듣기전_v49.html`.
