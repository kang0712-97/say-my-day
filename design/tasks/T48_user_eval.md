# T48 사용자 평가 (3분 미션 + 앱 안 설문) — 설계 확정 2026-11-04
상태: **설계 확정, 구현 전.** 구현은 T48b(새 대화). 배포·push는 사용자가 "배포 진행"이라 한 뒤에만.

## 왜
발표에서 "사람에게 써 보게 하는 테스트를 못 했다"고 밝혔다. 그 한계를 메운다. 알고 싶은 것: ① 사용이 자연스러웠나 ② 다시 쓸 의사 ③ 오류 ④ 좋은 점·아쉬운 점.

## 방식 (사용자 결정)
- 평가용 링크 `…/?eval=1`을 **Slack으로 공유**. 사용자가 **테스트해 본 화면 안에서** 설문까지 끝내고 제출한다.
- 저장은 **구글 시트**(Apps Script 웹앱이 한 줄씩 추가). 이유: Render 무료 플랜은 재시작하면 서버 파일이 사라지고, 공개 모드는 서버에 저장하지 않는다.
- `?eval` 없는 일반 접속은 **전혀 달라지지 않는다**(시험 항목).

## 흐름
1. `?eval=1` 첫 화면에 "3분 테스트" 안내(무엇을 하고, 일기 내용은 수집하지 않는다는 한 줄).
2. 미션 4칸 진행 표시(화면 위쪽 작게): ① 한 줄 일기 쓰기 ② 번역 결과 보기 ③ 단어 눌러 소리 듣기 ④ 퀴즈 1문제. 각 칸은 그 행동이 일어나면 켜진다(강제 순서 아님).
3. 퀴즈 1문제를 마치면(또는 "그만하고 설문으로" 버튼) 설문 카드. 한 화면에 한 문항, 탭 위주. 화면 모양은 그림일기 기준(`design-system-final-2026-10-29`, `/say-my-day-design` 스킬 절차).
4. 제출 → 감사 화면. 제출 실패 시 다시 시도 버튼(응답은 화면에 보관). 한 번 제출하면 같은 브라우저에서 중복 제출 막기.

## 설문 8문항 (문구는 한국어 가정 — Claude 추측, 사용자 확정은 문항·구조까지)
| # | 질문 | 답 |
|---|---|---|
| 1 | 설명 없이 쓰기 편했나요? | 1~5 |
| 2 | 어디서 막혔나요? | 복수: 막힌 곳 없음/시작 방법/일기 쓰기/번역 기다림/소리 듣기/단어 누르기/퀴즈/기타 |
| 3 | 겪은 문제가 있나요? | 복수: 없음/번역 실패/소리 안 남/병음·뜻이 이상함/화면 깨짐/너무 느림/기타 |
| 4 | 다시 쓰고 싶나요? | 1~5 |
| 5 | 쓴다면 얼마나 자주? | 매일/주 몇 번/가끔/안 씀 |
| 6 | 좋았던 점·아쉬운 점 한 줄(선택) | 글, "일기 내용은 쓰지 마세요" 안내, 글자 수 제한 |
| 7 | 배우려는 언어는? | 중국어/일본어/둘 다/기타 |
| 8 | 지금 수준(한 화면 세 줄) | 듣기·읽기·말하기 각 1~5. 양 끝 설명: 1=거의 모름, 3=쉬운 문장은 이해함, 5=자유롭게 씀 |
목표: 2분 안쪽. 1·4는 점수 양 끝에 말(불편함↔아주 편함 등)을 붙인다.

## 자동 기록 (입력 없음, 내용 없음)
단계별 도달 시간(초), 번역 실패 횟수, 음성 실패 횟수, 기기 종류(폰/PC)·화면 폭, **실제 쓴 언어 조합**(Q7과 비교용), 응답 시각, 무작위 응답 번호(사람과 연결 안 됨), `test` 표시(시험 응답 구분).

## 받지 않는 것 (지킬 것)
일기 내용, 번역 결과, 이름·이메일·IP. 일기는 민감하다. 자유 입력은 Q6 하나뿐이고 경고 문구를 붙인다. "테스트했다"는 말은 실제 사용자 응답이 들어온 뒤에만 쓴다.

## 시트 열(안)
응답번호, 시각, test, Q1, Q2, Q3, Q4, Q5, Q6, Q7, 듣기, 읽기, 말하기, 쓴 언어조합, 기기, 화면폭, 번역실패수, 음성실패수, t1~t4(초)

## 카드 분할
- **T48a 사용자 작업(약 5분)**: 구글 시트 만들기 + Apps Script 붙여넣기 + 웹앱 배포(누구나 접근) → 주소를 Claude에게 전달. 스크립트 코드는 Claude가 T48b 시작 때 준다(열 이름 위 기준). 주소는 비밀 키가 아니지만 채팅 외 파일에 커밋할 때는 환경변수로.
- **T48b 구현(새 대화)**: `?eval=1` 안내·진행 표시·설문 카드·제출·자동 기록. 시험은 분리 서버 + 임시 크롬 프로필, 시험 응답은 `test` 표시. 일반 접속 무변화·`npm test` 통과 확인. 백업 `backup/index_평가전_v94.html`.
- **T48c 배포·공유(사용자 "배포 진행" 승인 뒤)**: 로컬이 배포본보다 커밋이 많이 앞서 있음(배포 승인 요청서 `design/release-request.md`). 배포 후 실제 사이트에서 끝까지 한 번 제출해 시트 확인. 링크 공유 직전에 사이트를 열어 깨운다(Render 무료는 잠들면 첫 요청 30초~1분). Slack 공유 문구 제공.

## 남은 확인 (사람이)
휴대폰 화면 폭·소리·설문 탭 크기는 Claude가 직접 못 본다. 사용자 폰에서 한 번 확인.
