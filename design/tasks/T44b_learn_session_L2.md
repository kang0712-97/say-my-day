# T44b 학습 세션 L2 (따라 말하기 · 새 단어 · 문법 · 활용 문장)
상태: 완료(미확인: 실제 휴대폰, 중국어 문구). 계획: `T44_learning_flow_proposal.md`, 앞 단계 `T44a_learn_session_L1.md`.

## 카드 순서
시작 → [문장마다 ① 문장 → ② 따라 말하기 → ③ 새 단어(0~3장)] → ④ 문법 → ④ 활용 문장 → 마무리. (예시 일기: 문장 4 · 단어 카드 9 · 문법 3 · 활용 4 = 카드 약 28장. 분량은 실사용 후 조정.)
- 위쪽 알약이 지금 카드 종류를 알려 줌: `① 문장 2/4`, `② 말하기 2/4`, `③ 단어 1/3`(+ 옆에 `문장 2/4`), `④ 문법 1/3`, `④ 활용 문장 1/4`. 카드 모양도 다름: 단어 카드는 회색 종이, 문법·활용 카드는 왼쪽 굵은 줄(일기장 쪽).
- 아래 큰 버튼 글자가 다음에 올 것을 알려 줌(따라 말하기 / 단어 보기 / 다음 단어 / 문법 보기 / 활용 문장 / 다음 문장 / 다 봤어요).

## 한 일
- **② 따라 말하기**: 한국어 + 외국어 문장 + 듣기·느리게 듣기. **마이크는 꺼져 있으므로(`SPEAK_ON=false`)** 큰 버튼이 "소리 내어 말했어요", 작은 "건너뛰기"도 있음. 마이크를 켜면 마이크 버튼이 이 카드에 같이 나오고 버튼 글자는 일반 "다음"으로 바뀜(`lnMic`). 기록(`speak-log`)에는 남기지 않음(알아들음 확인이 아니라 자기 확인이므로).
- **③ 새 단어**: 그 문장 안에 들어 있는 핵심 단어 중 **단어장에 없는 것만 카드 한 장에 모아**(최대 6개, 길면 카드 안에서 스크롤 — 2026-11-03 사용자 의견 "단어는 짧으니 한 카드에 스크롤로"). 카드를 여는 순간 그 단어들이 **자동으로 단어장에 담김**("단어장에 담았어요", 누르면 빼기). 뜻·읽기·예문 1개. 이미 아는 단어는 생략. 이어 열 때 카드가 바뀌지 않게 처음 정한 단어 목록을 `learn-pos`에 저장.
- **④ 문법·활용 문장**: 문장별 연결 정보가 없어 1단계는 끝에 모아 보임(L5에서 문장별로). 기존 문법·활용 문장 부품(`learnItemBody`) 재사용.
- 마무리 카드: 새 단어 몇 개를 담았는지 알려 주고, 공부 마치기 / 일기 전체 읽기 / 전체 보기 / 처음부터 다시. (이제 단어·문법은 카드에서 다 보므로 "단어·문법 보기" 이동 버튼은 없앰 — 이전 제보 "단어를 누르면 전체 보기로 넘어간다" 해소.)
- 시험: 스모크는 카드 구성(문장·말하기·문법·활용 수), 모든 카드 순서대로 열기·종류별 점검, 새 단어 자동 담기·빼기, 이어 열기. 접근성은 카드 종류별 점검. 제한: 시험 중 담긴 단어는 시험이 끝에 비움.

## 알려진 것
- 목업(API 키 없음) 결과에서는 단어를 자동으로 담지 않음(실제 단어장 보호).
- 아직 없는 것: ⑤ 가리고 말하기, ⑥ 이어 말하기(L3), 카드별 새 자세·문구 정리(L4), 문법 문장별 연결(L5).
- 휴대폰 느낌·중국어 문구·카드 수가 많게 느껴지는지는 확인 못 함.
