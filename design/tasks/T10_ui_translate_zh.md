# T10 화면 문구 전체를 중국어로 (T9 이후)
상태: 쪼갬(진행 규칙 5) — T10a 완료, T10b~d 대기
## 쪼갠 단계 (2026-10-28)
- **T10a 완료(정적 HTML)**: 방식을 바꿨다 — 키를 새로 짓지 않고 **한국어 원문을 키로** 쓰는 `ZH` 사전과 `L('원문', {값})`(index.html의 `const ZH`). 정적 HTML은 `zhStatic()`이 처음 한 번 바꾼다(텍스트·aria-label·placeholder·data-start). 조각난 문장은 `data-th`+`T` 키(`wrap.read`·`set.privacy`·`writing.t`). 한국어 화면 회귀 없음. 남은 한글은 JS가 만드는 문구뿐.
- **T10b 완료(2026-10-28, 일기장·보관함·설정 시트 3개를 열어 zh 설정에서 한글 0 확인)**: JS가 만드는 일기장·보관함·설정 동적 문구(달력·요일·날짜 `toLocaleDateString`, 연속 일수, 동기화 `저장됨`, 음성 라벨(샤오샤오 등), 복습 카드 `due-text`, 빈 상태 안내, 삭제, `wrap-count`) — 시험은 `/private/tmp/…/dump.js` 방식(zh 설정에서 DOM의 한글 목록)
- **T10c 대기**: 번역 결과 렌더(`render`)·단어 페이지·글자별 풀이·퀴즈(`학습 퀴즈` 구역) 문구
- **T10d 대기**: 첫 사용 말풍선(coach)·내 표현 사전·토스트·`storageFull`·서버 메시지(`code` 기반)·번역 해설 안의 고정 문구(프롬프트 `system_prompt_zh_ja.md` 쪽 확인)
- 시험 도구: 분리 서버+`PRESET='{"intro-seen":"\"1\"","lang-src":"\"zh\"","lang-tgt":"\"ja\""}'`로 DOM에서 `[가-힣]` 남은 노드 덤프(위 T10a에서 쓴 스크립트와 같은 방식)

## 왜
T9의 문구 사전 틀에 한국어 약 430줄(`index.html`)과 서버 메시지 약 138줄을 키로 옮기고 중국어를 채운다. 학습 문장 자체가 아니라 **버튼·안내·설명·퀴즈 지시문·오류·튜토리얼(말풍선 6개)·설정·도움말**이 대상.

## 할 일 (예상)
1. 한글이 든 줄을 구역 주석별로 나눠 키로 옮긴다(인트로 → 쓰기 → 번역 결과 → 단어/문장 보관 → 퀴즈 → 설정·동기화 → 오류). 문구가 많아 한 대화에 다 안 되면 구역별로 카드를 쪼갠다(진행 규칙 5).
2. 중국어 번역은 AI로 초안을 만들고 사용자(또는 중국인 친구)가 검수하도록 표시. 퀴즈 지시문 등 학습 용어(병음·후리가나·성조)는 중국어 화자 관점으로 쓴다.
3. 번역 해설 안의 한국어 고정 문구(예: "끊어 읽기", "확인 필요", "이 문장에서")도 포함.
4. 시험: `data-t` 누락 검사(화면에 한글이 남았는지 zh 설정에서 DOM 검사), 한국어 화면 회귀.

## 완료 기준
- 입력 언어를 중국어로 두면 화면에 한글이 하나도 남지 않는다(정답 문장·사용자가 쓴 글 제외). 한국어 화면은 이전과 같다.
