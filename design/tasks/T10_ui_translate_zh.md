# T10 화면 문구 전체를 중국어로 (T9 이후)
상태: 대기(T9 완료 후) · 결과: (끝나면 기록)

## 왜
T9의 문구 사전 틀에 한국어 약 430줄(`index.html`)과 서버 메시지 약 138줄을 키로 옮기고 중국어를 채운다. 학습 문장 자체가 아니라 **버튼·안내·설명·퀴즈 지시문·오류·튜토리얼(말풍선 6개)·설정·도움말**이 대상.

## 할 일 (예상)
1. 한글이 든 줄을 구역 주석별로 나눠 키로 옮긴다(인트로 → 쓰기 → 번역 결과 → 단어/문장 보관 → 퀴즈 → 설정·동기화 → 오류). 문구가 많아 한 대화에 다 안 되면 구역별로 카드를 쪼갠다(진행 규칙 5).
2. 중국어 번역은 AI로 초안을 만들고 사용자(또는 중국인 친구)가 검수하도록 표시. 퀴즈 지시문 등 학습 용어(병음·후리가나·성조)는 중국어 화자 관점으로 쓴다.
3. 번역 해설 안의 한국어 고정 문구(예: "끊어 읽기", "확인 필요", "이 문장에서")도 포함.
4. 시험: `data-t` 누락 검사(화면에 한글이 남았는지 zh 설정에서 DOM 검사), 한국어 화면 회귀.

## 완료 기준
- 입력 언어를 중국어로 두면 화면에 한글이 하나도 남지 않는다(정답 문장·사용자가 쓴 글 제외). 한국어 화면은 이전과 같다.
