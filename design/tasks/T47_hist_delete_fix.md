# T47 일기장 일기 삭제가 안 되던 오류 + 이동 버튼 크기 (2026-11-03)
## 삭제 오류
- 증상: 일기장 목록에서 ⋯ → 삭제를 눌러도 확인 단추가 안 나와 일기가 지워지지 않음.
- 원인: 메뉴 바깥을 누르면 메뉴를 닫는 처리(`document` 클릭)가, 메뉴 안 "삭제" 단추를 눌러 목록이 다시 그려진 뒤 **화면에서 떨어진 단추**를 "바깥 클릭"으로 잘못 보고 확인 메뉴를 바로 닫았음(`#hist .vmenu` 선택자가 떨어진 요소에는 안 맞음. 단어 보관함 메뉴는 선택자가 달라 영향 없었음). T25부터 있던 오류.
- 수정: 눌린 요소가 화면에 붙어 있을 때(`isConnected`)만 바깥 클릭으로 본다. 시험(스모크)에 ⋯ → 삭제 → 확인 → 1편 남음·되살아나지 않음 추가. 브라우저에서 4편 → 3편으로 줄고 1.5초 뒤에도 유지 확인.
