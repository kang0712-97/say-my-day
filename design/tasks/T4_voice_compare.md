# T4 듣기 비교 페이지로 음성 고르기 (무료 음성만)
상태: 진행 중(사용자가 귀로 고르는 일만 남음) · 결과: (선택 후 기록)

## 진행 기록 (2026-10-27)
- 만든 것: `app/public/voice-test.html`(공개 모드에서는 404) + 서버 `/api/tts-test`(공개 모드 아님일 때만, 속도 ±50%·음높이 ±50Hz). 확인: 속도·음높이를 바꿔 모두 200, 길이가 달라짐(소리는 못 들음). 일본어 음성은 나나미·케이타 2종뿐(edge-tts 목록 확인). edge-tts는 pitch·volume 지원. 비교 페이지는 브라우저 기본 일본어 음성도 보여 줌.
- 사용법: `CHINESE_DIARY_DATA_DIR=/private/tmp/claude-501/trydata PORT=3002 node app/server.js` 후 http://localhost:3002/voice-test.html
- 남은 일: 사용자가 고른 음성·속도·음높이를 알려 주면 `voice-ja` 기본값·`EDGE_RATES`·`opt-rate`에 반영(현재 화면 속도는 0.75/0.9/1 세 단계뿐 → 고른 값이 -10% 밖이면 단계 추가 필요), 중국어도 비교할지 묻기.


## 왜
사용자 질문: 지금 음성이 가장 자연스러운 것인가? → 단정할 수 없음(일본어는 나나미·케이타 2종뿐, 귀로 비교한 적 없음). **유료·공식 음성 서비스는 쓰지 않기로 결정.** 무료 범위 안에서 사용자가 귀로 고른다.

## 할 일
1. 비교 페이지 `app/public/voice-test.html`(임시, 배포 때는 제외하거나 숨김): 같은 문장 3개(일기체 짧은 문장, 조사가 많은 문장, 읽기 까다로운 문장)를 후보마다 재생 버튼으로 듣게 한다. 후보: 나나미·케이타 × 속도 0.8/0.9/1.0/1.1(서버 `EDGE_RATES` 확인), 가능하면 브라우저 기본 음성(기기에 있는 일본어 음성)도.
2. 서버가 지원하는 음성·속도 값을 확인해 목록에 쓴다. 억양(pitch)·볼륨 조절이 edge-tts에서 되는지 확인하고 되면 후보에 넣는다.
3. 사용자가 고른 결과를 받아 기본 음성·기본 속도를 정한다(`voice-ja`, 설정 `opt-rate` 기본값). 중국어도 같은 비교를 원하는지 사용자에게 묻는다.

## 찾을 곳 (grep)
`EDGE_VOICES_BY_LANG`, `EDGE_RATES`, `/api/tts`, `opt-rate`, `opt-voice`, `fillVoiceSelect`

## 완료 기준
- 비교 페이지에서 모든 후보가 재생된다(Claude는 소리를 들을 수 없으므로 요청 성공·파일 길이만 확인).
- 사용자가 고른 음성·속도를 기본값으로 반영하고 카드에 기록. 비교 페이지를 배포에서 제외했는지 확인.
