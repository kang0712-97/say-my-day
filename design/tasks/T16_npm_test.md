상태: 완료
근거: `hardening-plan.md §5 T16` (읽고 시작)

## 할 일
기존 순수 검사들을 `npm test`로 묶고, 오늘 쓴 임시 화면 시험(`/private/tmp/claude-501/phone/*.js`, `t10c/check.js`)을 `tests/smoke/`로 승격. 러너가 분리 서버를 띄우고 끈다. 검사: 언어 문구 누출·자리표·360px 넘침·콘솔 오류.

## 결과
`npm test`(= `tests/run_all.js`)가 순수 검사 5개 + 화면 스모크(`tests/smoke/run.js`, 분리 서버 자동 기동·종료, API 호출 없음)를 차례로 돌려 통과 시 "전부 통과", 하나라도 실패하면 종료 코드 1. 스모크는 ko>zh·ko>ja·zh>ja 각각 쓰기·언어 고르기·결과·단어 미니 카드·단어 페이지·통독·퀴즈 16회·설정/일기장/보관함 시트를 360px 폭에서 돌며 한글 누출(중국어 화면)·자리표/undefined/NaN·가로 넘침·콘솔 오류를 검사. 전체 약 41초. 시험의 시험: 중국어 사전 항목 2개를 일부러 깨뜨리자 13건 실패로 잡힘, 되돌린 뒤 통과. 한계: 한국어 화면에서 중국어·일본어 문구가 섞여 새는 것은 검사하지 않음(원문과 구분 불가), 퀴즈 종류별 도달 여부는 세지 않음, `tests/`는 git 제외 폴더라 시험 파일은 저장소에 올라가지 않음(`package.json`의 test 줄만 올라감). `split_check`는 값을 단정하지 않아 오류 없이 도는지만 봄.
