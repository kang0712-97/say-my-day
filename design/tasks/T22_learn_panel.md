# T22 번역 학습 화면 + 설명 패널
상태: 완료(미확인: 휴대폰 화면, 소리, 중국어 문구)
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '기능별 화면 > 번역 학습', 보드 03(가운데), `design/tasks/T10c`·`T5`

## 할 일
1. 문장 카드: 원문 상자(+듣기), 번역문(ruby, 학습 대상 26/46), 문장 재생 버튼. 6개 섹션 고정 메뉴와 문장 번호 칸은 없앤다.
2. 단어를 누르면 하단 설명 패널(최대 64dvh, 자체 스크롤, 닫기, 원문·선택 문장 계속 보임). 탭 '단어/문법/활용'. 단어 탭: 발음·뜻·한자(글자) 풀이·관련 예문·단어 저장. 문장 저장과 단어 저장은 글자로 구분('단어 저장' → 채운 책갈피+'저장됨').
3. 문법·활용·확인 필요는 문맥 안으로: 확인 필요는 해당 구절 가까이(`.flag`), 문법/활용은 패널 탭. 기존 "마무리"(저장 개수·퀴즈 시작)의 새 위치를 정한다.
4. 목록/한 문장씩 보기(`#onebar`)와 '일기 전체 듣기' 진입 유지. 단어 페이지(글자 풀이 큰 화면)와 미니 카드를 패널로 통합하되 기능 손실 없이.
5. ≥1200px에서 본문 680 + 해설 320 병렬(선택).

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F1·F3·F6, 기존 6개 섹션의 정보 전부(번역·핵심 단어·문법·활용·확인 필요·마무리), 일본어 글자별 풀이(`/api/chars`), 일본어 확인 표시.

## 완료 기준
- 기존 6개 섹션 정보 도달 경로 표(섹션→새 위치)를 카드 결과에 적고 전부 ○.
- 패널: 열기·닫기·Esc/뒤로, 자체 스크롤, 선택 단어가 본문에서 계속 강조.
- 단어 저장/문장 저장 라벨·상태 구분, 저장 후 보관함 개수 반영.
- 3조합 렌더 스모크, 글자 200%·360px 넘침 0.

## 검증 방법
`npm test` 통과(분리 서버), 라이트·다크 × ko>zh·ko>ja·zh>ja × 폭 360/390 스크린샷을 해당 보드와 나란히 비교, 글자 200% 가로 넘침 0, 사용한 색 쌍을 `contrast-check`로 재계산. 소리·실기기는 "미확인"으로 적고 사용자에게 요청.
추가: `tests/ja/ui_render_check.js` 방식의 고정 샘플로 3조합 렌더, 단어 누르기→패널→저장 흐름 스크립트.

## 결과
문장 카드(원문 상자+번역 카드+둥근 재생 버튼)와 하단 설명 패널(단어/문법/활용 탭, 최대 64dvh)로 개편. `npm test` 전부 통과(스모크·접근성 3조합), 흐름 시험 3조합(ko>zh·ko>ja·zh>ja) 실패 0, 글자 200%·패널 열림 가로 넘침 0, 백업 `backup/index_learn_v37.html`.

**기존 6개 섹션 → 새 위치**
| 기존 섹션 | 새 위치 | 도달 |
|---|---|---|
| 01 번역 | 문장 카드(원문 상자·번역 ruby·재생·문장 저장·복사·해설 더 보기) | ○ |
| 02 핵심 단어 | 문장 속 단어를 누르면 패널 '단어' 탭(발음·뜻·글자별 풀이·이 문장에서·관련 예문·단어 저장), 목록 아래 "핵심 단어 N" 도구 칩 → 패널의 핵심 단어 목록 | ○ |
| 03 문법 포인트 | 도구 칩 "문법 포인트 N" 또는 패널 '문법' 탭(패턴·설명·예문·듣기·문장 저장) | ○ |
| 04 활용 문장 | 도구 칩 "활용 문장 N" 또는 패널 '활용' 탭(상황·문장·듣기·복사·문장 저장), 두 탭의 예문 속 단어도 눌러 단어 탭으로 | ○ |
| 05 확인이 필요한 부분 | 문장에 붙은 것은 해당 문장 옆 `확인 필요 N` 버튼(펼침), 문장에 붙지 않은 것만 목록 아래 "확인이 필요한 부분", 일본어 읽기 확인(`check`)은 단어 탭의 안내 | ○ |
| 06 마무리 | 목록 아래 "마무리"(저장 개수·퀴즈 시작·일기 전체 읽기), 상단 "일기 전체 읽기"도 유지 | ○ |

**동작 확인(분리 서버, 크롬)**: 열기·닫기 버튼·Esc·뒤로 가기(결과 화면 유지)·탭 전환·선택 단어 강조(`.wd.sel`)·패널이 선택 단어를 가리지 않게 스크롤·단어 저장(라벨 '단어 저장'→채운 책갈피+'저장됨', `aria-pressed`)·문장 저장(별+'문장 저장'/'문장 저장됨')과 보관함·마무리 개수 반영. 대비(라이트/다크): 잉크/바탕 15~17:1, 보조 글자 6.4~9:1, 비텍스트 테두리 4.3~5:1.

**결정·남긴 것**
- 원문 상자의 "듣기"는 만들지 않았다(원문은 한국어·중국어 음성이 별도 필요, 무료 음성 범위 밖). 필요하면 후속 카드.
- 단어 페이지(`#wpage`)는 보관함의 단어 열기(`data-wopen`)에서만 남겼다 → T24에서 패널과 합친다. 결과 화면의 미니 카드는 패널로 대체했다.
- 1200px 이상 본문 680+해설 320 병렬(선택 항목)은 하지 않았다(T27 후보).
- 문법·활용은 일기 전체에 대한 것이라 패널 탭이 문장과 무관하게 전체 목록을 보여 준다.
- 시험 도구 `tests/smoke`·`tests/a11y` 시나리오는 미니 카드 대신 패널 흐름으로 고쳤다(`tests/`는 git 제외).
- **미확인(사용자 확인 요청)**: 휴대폰 실제 화면·터치 스크롤, 단어 누를 때 소리, 중국어 화면 문구('保存单词' 등 새 문구 8개 검수).
