# T32 따라 말하기: 내 발음 확인 + 말한 개수 기록
상태: 완료(미확인: 실제 마이크·인식 정확도, 휴대폰 화면, 중국어 문구)
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 문장마다 🎤 "따라 말하기". 브라우저 음성 인식(무료, 유료 서비스 금지)으로 말한 내용을 글자로 받아 원문과 비교, 맞은 글자는 초록·놓친 글자는 표시(색만으로 구분하지 않기).
2. 단어도 같은 방식으로 말해 보기(단어 카드/복습에서).
3. 안내 문구는 "발음 채점"이 아니라 "알아듣는지 확인"(성조·억양은 판정 못 함). 지원하지 않는 브라우저(아이폰 사파리 등)는 버튼을 숨기거나 안내.
4. 마이크 권한 거절·무음·인식 실패 상태와 문구(ko/zh). 음성은 서버에 보내지 않는다(브라우저 안에서 처리, 설정에 안내 문구).
5. **말한 횟수 기록:** 말해 본 단어 수·문장 수(중복 없이 고유 개수 + 총 횟수)를 브라우저 저장소에 저장. 내보내기·불러오기·전체 삭제(F9)에 포함, 스키마 버전 올리기. 표시는 T34에서.

## 반드시 유지할 기능
F4, F9(스키마 버전·병합 규칙), F2(ko/zh 문구), F13.

## 완료 기준·검증
가짜 인식 결과를 넣어 비교 로직 단위 시험 + 저장·병합·삭제 시험, `npm test` 통과. 실제 마이크·인식 정확도는 사용자 휴대폰. 이미지: 마이크 켜진 새(기존 06-listening 재사용 가능, 새 그림이 있으면 교체).
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.

## 결과
문장·단어 🎤 "따라 말하기"(브라우저 음성 인식, 무료)를 아래 공용 시트로 추가하고 말한 횟수를 `speak-log`에 기록. 시험: `tests/speak_check.js` 19개, 스모크에 가짜 인식기(맞음·절반·마이크 거절 + 기록 n=2·닫기) 추가, 저장·병합·서버 동기화·서버 지우기 직접 확인.
- 위치: 번역 문장 줄(라벨 버튼), 단어 페이지(라벨 버튼), 단어 패널·예문·문법 예문·보관함 단어/문장·복습 정답 화면·따라 읽기 페이지(아이콘 버튼). 인식기가 없는 브라우저는 버튼을 그리지 않고 설정에 안내.
- 비교: 글자 단위 LCS(`app/public/speak-check.js`). 문장부호·공백 무시, 가타카나=히라가나. 맞은 글자 실선 밑줄, 놓친 글자 물결 밑줄+호박색 배경+"N글자를 놓쳤어요: 글자" 문구(색만으로 구분하지 않음). 성조·억양은 판정 안 한다고 시트·설정에 표시.
- 기록: `speak-log` = [{id(`언어:w|s:원문`), k, t, zh, n, at}], 말소리가 글자로 인식된 시도마다 n+1(정확도와 무관). `SYNCED`·서버 `DATA_KEYS`에 추가, 내보내기에 포함, `SCHEMA` 2(옛 파일은 가져올 때 `speak-log`를 건드리지 않음), 합치기는 횟수 큰 쪽·최근 시각. 전체 삭제는 localStorage 전체+서버 비우기라 자동 포함. 표시는 T34(`SpeakCheck.stats`).
- **주의 1(카드 문구와 다른 점):** 카드에는 "음성은 서버에 보내지 않는다(브라우저 안에서 처리)"로 되어 있으나, 크롬의 음성 인식은 소리를 구글 서버로 보낸다. 그래서 설정 안내를 "이 앱의 서버로는 보내지 않지만 브라우저 회사의 서비스로 갈 수 있어요"로 썼다. `design/hardening-plan.md` 부록 A에도 추가.
- **주의 2(알려진 한계):** 일본어는 인식기가 한자/히라가나를 원문과 다르게 적으면(友達↔ともだち) 놓친 것으로 나온다. 한자 읽기(reading)로도 비교하는 개선은 하지 않았다(T32 범위 밖, 필요하면 후속).
- 미확인: 실제 마이크·인식 정확도(휴대폰 크롬), 아이폰 사파리에서 버튼이 보이는지·동작하는지, 중국어 문구 검수. 이미지는 새 그림 없이 쓰지 않았다(상태 안내는 글자+아이콘).
