# T32 따라 말하기: 내 발음 확인 + 말한 개수 기록
상태: 대기
근거: 2026-10-30 사용자 사용 피드백과 UX 제안(승인됨). `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때), `design/redesign-plan.md` §4 기능 확인표

## 할 일
1. 문장마다 🎤 "따라 말하기". 브라우저 음성 인식(무료, 유료 서비스 금지)으로 말한 내용을 글자로 받아 원문과 비교, 맞은 글자는 초록·놓친 글자는 표시(색만으로 구분하지 않기).
2. 단어도 같은 방식으로 말해 보기(단어 카드/복습에서).
3. 안내 문구는 "발음 채점"이 아니라 "알아듣는지 확인"(성조·억양은 판정 못 함). 지원하지 않는 브라우저(아이폰 사파리 등)는 버튼을 숨기거나 안내.
4. 마이크 권한 거절·무음·인식 실패 상태와 문구(ko/zh). 음성은 서버에 보내지 않는다(브라우저 안에서 처리, 설정에 안내 문구).
5. **말한 횟수 기록:** 말해 본 단어 수·문장 수(중복 없이 고유 개수 + 총 횟수)를 브라우저 저장소에 저장. 내보내기·불러오기·전체 삭제(F9)에 포함, 스키마 버전 올리기. 표시는 T34에서.

## 반드시 유지할 기능
F4, F9(스키마 버전·병합 규칙), F2(ko/zh 문구), F13.

## 완료 기준·검증
가짜 인식 결과를 넣어 비교 로직 단위 시험 + 저장·병합·삭제 시험, `npm test` 통과. 실제 마이크·인식 정확도는 사용자 휴대폰. 이미지: 마이크 켜진 새(기존 06-listening 재사용 가능, 새 그림이 있으면 교체).
공통: 백업 먼저(`backup/index_<이름>_v44~`), 분리 서버로만 시험, `npm test` 통과, 사용자 확인 항목은 "미확인"으로 기록.
