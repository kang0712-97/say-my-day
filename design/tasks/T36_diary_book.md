# T36 내 일기책 — 쌓인 하루를 책처럼 넘기며 다시 말해보기
상태: A·B 완료(미확인: 실기기 스와이프·소리·마이크, 휴대폰 화면, 중국어 문구). C는 발표 후
근거: 2026-11-02 사용자 요청. "일기 기록을 책처럼 넘기며, 내가 쓴 문장과 다른 언어 문장+발음을 보고 클릭해서 다시 말해볼 수 있게. 일기의 장점(하루가 쌓임)과 언어 학습의 장점이 모두 적용돼야 함." 다시 들어올 이유 = 쌓인 것이 눈에 보이고, 과거의 내 문장을 다시 말하게 되는 것.

## 이미 있는 것 (새로 저장할 데이터 없음)
- 일기 1편 = `diary-history` 항목 `{id, at, diary, result, lang, src}`. `result.sentences[]`에 내 문장(ko)과 학습 언어 문장(zh), 읽기는 `readTokens`/`plainPinyin`으로 만든다.
- 소리·따라 읽기·따라 말하기(`playBtn`, `spkBtn`, `speak-log`)는 문장 문자열만 있으면 동작.
- 언어 조합별 구분(`inScope`)으로 지금 배우는 조합의 일기만 책이 된다.

## 설계
**구성**: 표지 → 일기 1편 = 1쪽(왼쪽 위 날짜·요일, 문장 쌍 나열) → 마지막 쪽은 오늘(책은 마지막 읽은 쪽 책갈피에서 열린다).
- **표지**: "나의 이야기 · 한국어→중국어", 쓴 날 N일 · 문장 M개 · 단어 K개, 처음 쓴 날. (쌓임을 보이는 곳)
- **한 쪽**: 문장마다 ① 내가 쓴 문장(작게, 먹색) ② 학습 언어 문장(크게, 글자 위 읽기) ③ ▶ 듣기 ④ 🎤 말해보기(기존 따라 말하기 시트) ⑤ 문장 자체를 누르면 다시 말해보기. 긴 일기는 한 쪽에 문장 6개까지, 넘으면 다음 쪽으로 이어진다.
- **넘기기**: 좌우 스와이프 + 이전/다음 버튼 + "12 / 38" 쪽수 + 쪽수로 건너뛰기(달력과 연결). 움직임 줄이기면 페이드. 키보드 ←→.
- **가리고 말하기(2단계)**: 학습 언어 문장을 가리고 내 문장만 보고 말해 본 뒤 눌러서 확인. 일기책만의 복습.
- **문장별 말한 표시**: 이미 `speak-log`에 있는 기록으로 "말해 본 문장"에 작은 표식(색이 아니라 아이콘+글자).
- **진입**: 일기장 시트 위쪽 "책으로 보기", 홈의 "내 일기책" 링크. 기존 일기 목록·달력은 그대로(찾기용).

## 일기의 장점 / 언어의 장점 대응
| 일기 | 언어 학습 |
|---|---|
| 날짜·요일이 붙은 쪽, 표지의 쌓인 수, 책갈피 | 읽기(병음·후리가나) 병기, 내 말 ↔ 학습 말 한 쌍 |
| 내 원문이 그대로 남음 | 듣기·따라 말하기·가리고 말하기 |
| 오래된 쪽을 넘겨 보는 회상 | 같은 문장을 몇 주 뒤 다시 말함(간격 반복 효과) |

## 단계
- **A (T36a, 발표 전 가능)**: 책 화면 — 표지, 쪽 넘기기, 문장 쌍+읽기, 듣기, 말해보기, 문장 눌러 다시 말하기, 책갈피. 3개 조합·중국어 문구.
- **B (T36b)**: 가리고 말하기, 말한 문장 표식.
- **C (T36c, 발표 후)**: 홈 "오늘의 한 쪽"(예전 쪽을 하나 펼쳐 다시 말하기 = 다시 들어올 이유), 월별 목차, 책 전체 PDF(T35 인쇄 방식 확장), 쪽 넘김 소리·종이 질감.

## 결정할 것 (사용자)
1. 쪽 단위: 일기 1편 = 1쪽(추천, 긴 일기는 6문장씩 이어짐) vs 문장 하나 = 1쪽.
2. 열리는 위치: 마지막으로 읽던 쪽(추천) vs 항상 가장 최근 쪽.
3. 발표 전에 A까지만 할지, B(가리고 말하기)까지 할지.
