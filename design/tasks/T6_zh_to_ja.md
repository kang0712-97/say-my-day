# T6 중국어 입력 → 일본어 출력 조합(zh>ja) 추가
상태: 대기 · 결과: (끝나면 기록)

## 왜
사용자 요청(2026-10-27): 중국어로 쓴 일기를 일본어로 번역해 배우는 조합을 추가한다. 지금 켜진 조합은 `ko>zh`·`ko>ja`뿐.

## 먼저 사용자에게 물을 것 (카드 시작 때 한 번에)
1. 해설(뜻풀이·문법 설명)은 **한국어**로 둘지, 중국어 화자용으로 **중국어**로 쓸지. 화면 문구는 한국어 고정이 원칙(README 결정 6)이므로 기본 제안은 한국어 해설.
2. 입력이 중국어 간체인지 번체도 받을지(기본: 둘 다 받고 출력은 일본어).

## 할 일 (예상)
1. 서버: `PAIRS`에 `'zh>ja'`와 규칙 파일 `prompts/system_prompt_zh_ja.md` 추가(`system_prompt_ja.md`를 바탕으로, 입력 언어와 해설 언어만 바꾼다). `/api/langs` 응답에 자동 반영되는지 확인.
2. 입력 검사: 입력이 실제 중국어인지(한자 비율·가나/한글 섞임) 조합 검사. 한국어 일기를 zh 입력으로 보내는 실수를 막는 안내.
3. 화면: 언어 고르기에서 입력 "중국어" 선택 가능, 칩·안내 문구가 `srcName()`을 쓰는지 확인(T1에서 일부 처리). 입력란 `lang` 속성과 글꼴, 병음 입력 도움 필요 여부 확인.
4. 일본어 읽기·후리가나·음성·글자별 풀이(T1~T5)는 학습 언어 기준이라 그대로 동작하는지만 확인.
5. 용어집(`glossLang`)과 일기 꼬리표(`srcLang`)가 zh로 저장·표시되는지 확인.

## 찾을 곳 (grep)
`PAIRS`, `pairOf`, `buildSystemPrompt`, `LANG.src`, `srcName`, `langTags`, `lp.src`, `system_prompt_ja.md`

## 완료 기준
- 중국어 일기 3개(일상·감정·간단한 업무)가 일본어로 번역되고 후리가나·단어·퀴즈가 나온다. 한국어 입력을 zh로 넣으면 안내가 뜬다.
- ko>zh, ko>ja 회귀 없음. 기존 일기의 꼬리표가 바뀌지 않는다.
- 사용자 확인 요청: 일본어 번역의 자연스러움(원어민 검수 전), 휴대폰 언어 고르기 화면.
