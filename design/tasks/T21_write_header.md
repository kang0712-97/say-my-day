# T21 쓰기 화면 + 상단 바·메뉴
상태: 완료(미확인: 휴대폰 키보드 열림·화면, 중국어 문구 검수)
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '기능별 화면 > 쓰기', 보드 03(왼쪽)·04, 계획서 §3·§6-2

## 할 일
1. 상단 바: 로고 `say my day`, 일기장·보관함 링크, ☰ 메뉴(설정·둘러보기 다시 보기·테마). 하단 탭바 제거. 결과로 되돌아가는 길(쓰기 화면의 "방금 번역" 링크 또는 ←)을 정하고 기록.
2. 쓰기: 날짜, 언어 선택 칩(`#lang-chip`), 복습할 단어 N개 보조 링크(`#due-card` 대체, 입력을 막지 않음), 입력 영역을 가장 크게(라벨 "오늘의 이야기", 글자수 `n / 1000`, 지우기), "이런 이야기로 써보세요" 칩(대신 써 주는 것처럼 보이지 않게), CTA '번역하고 배우기' 56px 캡슐.
3. 새: `02-writing` 96px, 입력창을 밀어내지 않음.
4. 번역 중: 입력 유지, 중복 제출 막기, 텍스트 진행 안내+`03-thinking-translation`. 오류: 입력 유지, '다시 시도', `10-retry-help`. 서버 깨우기 안내(`#wake-msg`)+`11-walking`.
5. 키보드가 열려도 CTA와 입력이 가려지지 않게(`visualViewport`).

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F1·F2·F11·F12. id 유지: `#diary #go #count #examples #lang-chip #status #wake-msg`. 1000자 제한, 복습 대기 동작, 언어 고르기·인트로 연결.

## 완료 기준
- 보드 03 왼쪽·04 상단과 구성이 일치(문구는 앱 사전 기준, 새 `ZH` 문구 추가+`i18n_keys_check` 통과).
- 번역 실패 시 입력이 남고 '다시 시도'로 같은 입력 재요청, 번역 중 CTA 중복 클릭 무시.
- 하단 탭 없이 일기장·보관함·설정·결과 복귀 모두 도달 가능.
- 모든 조작 44px 이상, 포커스 표시 2px.

## 검증 방법
`npm test` 통과(분리 서버), 라이트·다크 × ko>zh·ko>ja·zh>ja × 폭 360/390 스크린샷을 해당 보드와 나란히 비교, 글자 200% 가로 넘침 0, 사용한 색 쌍을 `contrast-check`로 재계산. 소리·실기기는 "미확인"으로 적고 사용자에게 요청.
추가: 모의 실패(서버 오류 응답)로 오류 상태 확인, 휴대폰 키보드 열림은 사용자 확인(미확인 가능).

## 결과
하단 탭 폐지, 상단 바(로고·일기장·보관함·☰ 메뉴[설정·둘러보기 다시 보기·테마])로 교체. **결과 복귀 결정:** 결과 화면은 ←(`#hdr-back`)로 쓰기 화면에 돌아가고, 쓰기 화면에는 번역 결과가 있을 때만 "방금 번역 보기 ›"(`#tab-result`)가 나타남(결과가 없으면 숨김). 로고(`#tab-write`)는 쓰기 화면으로. id(`tab-*`·`go`·`diary`·`count`·`examples`·`lang-chip`·`status`·`wake-msg`·`due-*`) 유지.
쓰기: 날짜(큰 글씨)+언어 칩(`한국어 → 중국어 ⌄`)+복습 링크(`복습할 것 N개 ›`)+새 02(96px), 입력 상자(회색 면, 18/30, 글자수·지우기 `#clear`), "이런 이야기로 써보세요" 2×2 칩, CTA 56px '번역하고 배우기'. 오류: 입력 유지+새 10+'다시 시도'(`#retry`), 서버 깨우기: 새 11, 번역 중 오버레이: 새 03. 번역 중 CTA 두 번 눌러도 요청 1회(시험 확인), 재시도 시 같은 입력으로 재요청(시험 확인). 키보드: `visualViewport`로 `--kb` 여백.
시험: `npm test` 전부 통과, 라이트·다크·ko>zh·ko>ja·zh>ja 스크린샷 보드 03 왼쪽과 일치, 메뉴·오류 스크린샷 확인. 새 ZH 문구 8개 추가(`i18n_keys_check` 통과). 부수 수정: 새 클래스 `.today`가 달력 `.cal-day.today`와 겹쳐 200% 넘침이 생겨 `.today-row`로 바꿈.
남김: 실제 휴대폰 키보드 열림, 360px 실물, 중국어 문구(`design/zh-review.csv`에 새 문구 추가는 T27에서). 오류 배너 경고 아이콘이 새 그림 위 줄에 따로 놓임(T27에서 다듬기).
