# T21 쓰기 화면 + 상단 바·메뉴
상태: 대기
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '기능별 화면 > 쓰기', 보드 03(왼쪽)·04, 계획서 §3·§6-2

## 할 일
1. 상단 바: 로고 `say my day`, 일기장·보관함 링크, ☰ 메뉴(설정·둘러보기 다시 보기·테마). 하단 탭바 제거. 결과로 되돌아가는 길(쓰기 화면의 "방금 번역" 링크 또는 ←)을 정하고 기록.
2. 쓰기: 날짜, 언어 선택 칩(`#lang-chip`), 복습할 단어 N개 보조 링크(`#due-card` 대체, 입력을 막지 않음), 입력 영역을 가장 크게(라벨 "오늘의 이야기", 글자수 `n / 1000`, 지우기), "이런 이야기로 써보세요" 칩(대신 써 주는 것처럼 보이지 않게), CTA '번역하고 배우기' 56px 캡슐.
3. 새: `02-writing` 96px, 입력창을 밀어내지 않음.
4. 번역 중: 입력 유지, 중복 제출 막기, 텍스트 진행 안내+`03-thinking-translation`. 오류: 입력 유지, '다시 시도', `10-retry-help`. 서버 깨우기 안내(`#wake-msg`)+`11-walking`.
5. 키보드가 열려도 CTA와 입력이 가려지지 않게(`visualViewport`).

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F1·F2·F11·F12. id 유지: `#diary #go #count #examples #lang-chip #status #wake-msg`. 1000자 제한, 복습 대기 동작, 언어 고르기·인트로 연결.

## 완료 기준
- 보드 03 왼쪽·04 상단과 구성이 일치(문구는 앱 사전 기준, 새 `ZH` 문구 추가+`i18n_keys_check` 통과).
- 번역 실패 시 입력이 남고 '다시 시도'로 같은 입력 재요청, 번역 중 CTA 중복 클릭 무시.
- 하단 탭 없이 일기장·보관함·설정·결과 복귀 모두 도달 가능.
- 모든 조작 44px 이상, 포커스 표시 2px.
