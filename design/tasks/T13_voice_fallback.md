# T13 향상된 음성(edge-tts)을 선택 기능으로 낮추기 + 폴백 확인
상태: 대기
근거: `hardening-plan.md §2` (읽고 시작)

## 할 일
서버 `EDGE_TTS_ENABLED` 스위치(꺼지면 `/api/langs`가 음성 없음 응답), 설정에 '외부 서비스라 중단될 수 있어요' 문구, edge 없이 서버를 띄워 듣기·따라 읽기·퀴즈·통독 점검, 음성 요청 5xx 때 폴백과 토스트 1회, 기기 음성 현황표는 사용자 확인 요청.

## 완료 기준
- edge-tts를 끈 상태에서 모든 듣기 화면이 오류 없이 기기 음성으로 동작.
