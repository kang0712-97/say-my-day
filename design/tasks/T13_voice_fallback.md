# T13 향상된 음성(edge-tts)을 선택 기능으로 낮추기 + 폴백 확인
상태: 완료(미확인: 실제 기기 음성 현황표, 중국어 문구 검수, 대안 서비스 조사는 하지 않음)
근거: `hardening-plan.md §2` (읽고 시작)

## 할 일
서버 `EDGE_TTS_ENABLED` 스위치(꺼지면 `/api/langs`가 음성 없음 응답), 설정에 '외부 서비스라 중단될 수 있어요' 문구, edge 없이 서버를 띄워 듣기·따라 읽기·퀴즈·통독 점검, 음성 요청 5xx 때 폴백과 토스트 1회, 기기 음성 현황표는 사용자 확인 요청.

## 완료 기준
- edge-tts를 끈 상태에서 모든 듣기 화면이 오류 없이 기기 음성으로 동작.

## 결과
서버 `EDGE_TTS_ENABLED=0`이면 `/api/tts-status`가 음성 없음으로 응답하고 화면이 기기 음성만 보여 줌. 음성 파일 요청이 실패하면 `edgeDown()`이 기기 음성으로 바꾸고 다시 시도하며 토스트는 한 번만. 설정에 "외부 서비스라 중단될 수 있어요" 문구(향상된 음성이 있을 때만 표시), 기기 음성이 없을 때 "기기 설정에서 음성 데이터 설치" 안내. 분리 서버 시험 3가지(끔·음성 요청 실패·정상): 화면 오류 0건, 끔은 안내문·토스트 없이 기기 음성 목록, 실패는 토스트 1회+목록이 기기 음성으로 전환, 정상은 변화 없음. 시험은 듣기 버튼 호출과 서버 응답까지만 봤고 소리는 못 들음. 통독·퀴즈 듣기는 같은 `edgeDown()`을 쓰지만 따로 돌려 보지 않음(통독은 실패한 문장만 건너뜀). `backup/index_음성폴백전_v29.html`.
