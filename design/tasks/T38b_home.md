# T38b 홈 재구성 — 일기 쓰기가 메인, 복습은 아래, 주간은 새의 말
상태: 완료(미확인: 휴대폰 화면, 다크 모드·일본어 조합 눈으로 확인, 중국어 문구)
## 한 일
- 홈 순서: 날짜·언어·새 → **새의 주간 멘트(말풍선)** → (오늘 일기가 있으면 "이어서 공부하기"·새 일기) → **일기장 쪽(쓰기 칸)** → 구분선 아래 **3분 복습·복습할 것·내 일기책**.
- 쓰기 칸: 왼쪽 굵은 책등 선 + 옅은 가로줄(줄 간격 30px=글줄) + 종이 바탕 = 펼친 일기장 한 쪽.
- 주간 돌아보기: 클릭해서 보는 링크 → 새 멘트 `weekSay()`. 연속(쓴 날) 2일 이상 "N일 연속 일기를 쓰고 있짹. 잘 하고 있짹", 이번 주 활동 있으면 "이번 주에 N일 같이 했짹", 쉬었으면 "오랜만이짹. 천천히 해도 괜찮짹", 처음엔 "안녕짹!…". 말풍선을 누르면 기존 주간 상세 시트도 열림(메뉴에도 있음). 압박·벌칙 문구 없음.
- `#week-link`·`#quick-card`·`#due-card`·`#book-link` id 유지, 복습 영역이 비면 자동으로 숨김(`:has`).
## 일기장 컨셉 점검
① 일기장 쪽 모양(책등·줄) ✓ ② 새가 말해 줌 ✓ ③ 쌓인 것은 주간 멘트·일기장 배지 ✓(깃털 달력은 T38f)
## 시험
분리 서버, 일기 3편(연속 3일)+단어 1개 데이터로 홈 스크린샷 확인, `npm test` 통과. 백업 `backup/index_홈재구성전_v55.html`.
