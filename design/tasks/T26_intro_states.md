# T26 인트로·언어 고르기·둘러보기·상태 이미지
상태: 대기
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '화면별 배치', 계획서 §5(상태→이미지), `design/tasks/T9`

## 할 일
1. 인트로 2장과 언어 고르기를 새 스타일로(`01-hello` 약 200px). 입력 언어에 따라 UI 문구·글꼴 전환 유지.
2. '예시로 둘러보기' 말풍선 6개를 새 스타일로 다시 맞춤(시안 없음 → 규칙 파생).
3. 계획서 §5의 상태→이미지 표를 보드와 대조해 확정하고, 모든 상태가 글자+아이콘을 함께 갖는지 확인(캐릭터만으로 안내하지 않음). 새 규칙 점검: 쓰는 장면만 펜을 날개로, 나머지는 머리 옆.

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F2·F11·F12. 첫 방문 흐름, 언어쌍 선택 저장, 둘러보기 건너뛰기, 개인정보 안내 문구.

## 완료 기준
- 첫 방문부터 쓰기·번역까지 새 화면으로 끊김 없음.
- 이미지 12종이 표대로 쓰이고, 쓰지 않을 이미지는 표에 '미사용'으로 기록.
- 모든 상태 화면에 텍스트 안내 존재(이미지 숨겨도 의미 전달).

## 검증 방법
`npm test` 통과(분리 서버), 라이트·다크 × ko>zh·ko>ja·zh>ja × 폭 360/390 스크린샷을 해당 보드와 나란히 비교, 글자 200% 가로 넘침 0, 사용한 색 쌍을 `contrast-check`로 재계산. 소리·실기기는 "미확인"으로 적고 사용자에게 요청.
