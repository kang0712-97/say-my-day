- 32장을 기존 74장과 같은 잘라내기 상자(33,35,1232,1234)·360px webp로 변환해 `img/cos/G03~G10/`에 추가(약 530KB). 모든 그림의 내용이 상자 안에 들어옴.
- `COS_EXTRA`에 4개 이름 등록 → **생각 중(think)**: 번역 기다리는 화면, **앗·다시(oops)**: 오류·다시 시도 화면(예전엔 그림이 비어 있었음), **간지러움(giggle)**: 첫 화면에서 새를 5번 넘게 빠르게 누를 때, **깜짝(surprised)**: 새를 가끔 첫 번에 눌렀을 때. 알 단계는 그대로 알 한 장.
- 백업 `backup/index_추가그림전_v81.html`

## 같이 정리한 것(사고 기록)
- 화면 시험에서 `study-days`를 미리 넣은 상태(가짜 학습일 23개)로 실제 서버(포트 3000)를 열었더니 **실제 `data/userdata.json`으로 동기화돼 새 단계가 6단계로 올라가 있었다**. 정리 전 파일을 `backup/userdata_정리전_20261102.json`에 두고, 서버 파일의 `study-days`에서 날짜가 아닌 항목 23개를 지움(실제 1일분만 남음). 일기·단어·표현 사전 등 사용자가 쓴 데이터는 건드리지 않음.
- 재발 방지: 앱이 `study-days`에서 날짜 형식이 아닌 항목을 불러올 때·합칠 때 걸러 냄(`goodDay`). 앞으로 화면 시험은 **분리한 서버(CHINESE_DIARY_DATA_DIR)** 에서만 한다.
- 이미 기기에 합쳐졌던 가짜 항목도 새 화면을 열면 자동으로 지워진다.
