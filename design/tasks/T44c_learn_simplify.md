# T44c 학습 세션 단순화 (2026-11-03 사용자 요청)
상태: 완료(미확인: 휴대폰, 중국어 문구). 앞 단계 T44a·b를 대체한다.
요청: "구성이 너무 복잡해. 문장 하나씩 들으면서 말해 보고, 단어 리스트 외우고, 문법·활용 문장은 따로 하지 말고, 전체 읽어 보기로 끝내자. 단어가 많은데 리스트에 나오는 단어는 너무 적다."

## 새 순서
시작 → **문장마다 1장**(듣고 소리 내어 따라 말하기) → **단어 리스트 1장** → **전체 읽기**(마무리) .
- 문장 카드: 한국어 + 외국어(글자 누르면 뜻) + 듣기·느리게 듣기 + "설명 보기" + 큰 버튼 "소리 내어 말했어요"(마이크가 꺼져 있어서. 켜면 마이크 버튼이 같이 나옴) + 건너뛰기. 말하기 카드를 따로 두지 않음.
- **단어 리스트**: 일기 문장에 나온 단어를 **나온 순서대로 모두**(조사·부호·뜻 없는 말 제외). 예시 일기: 전에는 핵심 단어 9개만 → 이제 24개. 각 줄: 단어(읽기)·뜻·듣기·★(단어장 담기/빼기). **"뜻 가리기"**를 켜면 뜻이 가려지고 눌러서 확인(외우기). 핵심 단어(AI가 고른 것)는 보는 순간 단어장에 자동으로 담기고, 나머지는 ★을 눌러 담음(단어장이 하찮은 말로 불어나지 않게).
- **전체 읽기**: 마지막 카드의 "전체 읽기 시작" → 기존 일기 전체 읽기(따라 읽기) 화면으로. 거기서 끝나면 기존 마무리(새 성장). 공부 마치기·전체 보기·처음부터 다시도 같은 카드에 있음.
- 없앤 것: 문법 카드·활용 문장 카드·단어 카드 묶음(긴 목록 화면 "전체 보기"에는 그대로 있음).
- 위쪽 알약: `① 문장 k/N` → `② 단어 24` → `③ 전체 읽기`.

- 문법 문장별 연결(L5)은 이 구성에서는 필요 없어짐(문법은 전체 보기에서만).
