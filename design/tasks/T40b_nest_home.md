# T40b·c 내 새 첫 화면 + 이름 + 터치 반응
상태: 완료(미확인: 휴대폰 화면, 중국어 문구, 터치 느낌)
계획: `T40_costume_apply_plan.md`. 모양은 사용자가 샘플(mock2.png)로 확정(2026-11-02).

## 결정
- 첫 화면 = "내 새" 화면. 새가 가장 큰 칸, 언어 표시는 맨 위에 작게(날짜는 오른쪽에 작게), 아래 고정 버튼 "일기 쓰러 가기"로 쓰기 화면에 들어감.
- 새 이름은 처음에 사용자가 정하고 뒤에 "짹"을 붙여 부른다(하나 → 하나짹, 직접 "짹"까지 써도 한 번만). 8글자까지, `bird-name`에 저장(기기별). 이름 바꾸기 있음.
- 쓰기 화면: 날짜·날씨 칸 + **네모 테두리 일기 칸**(가로줄). 새·단계 막대는 첫 화면으로 옮김. 언어 선택 칩도 첫 화면으로.

## 한 일
- 화면 3개: 첫 화면(`#v-nest`, 앱 시작 상태) → 쓰기(`#v-write`) → 번역 결과(`#result`). 로고를 누르면 첫 화면, "일기 쓰러 가기"는 쓰기. 브라우저·휴대폰 뒤로 가기: 쓰기 → 첫 화면, 결과 → 쓰기(`history.state.wr`).
- 첫 화면 구성: 말풍선(이번 주 말, 누르면 주간 시트) · 새(250px, 숨 쉬듯 움직임) · 이름·"○○새 · N일째 함께해요" · 성장 막대와 "다음 성장까지 N일" · 쓴 날/일기/문장/단어 보드 · 최근 7일 점 · (오늘의 한 문장·복습 카드는 보드 아래) · 하단 고정 버튼(오늘 이미 썼으면 "오늘 한 편 더 쓰기").
- 새를 누르면: 통통 튀고 동작 그림이 바뀌며 한마디(앱 안 문구, AI 호출 없음). 5번 이상 빠르게 누르면 "간지러워요짹! 하하". 알은 흔들리며 "톡톡!". 3초 뒤 원래대로. `prefers-reduced-motion`이면 움직임 없이 그림·말만 바뀜.
