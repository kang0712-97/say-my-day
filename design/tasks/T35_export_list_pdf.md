# T35 저장한 단어·문장 목록 PDF로 내려받기
상태: 대기
근거: 2026-11-02 사용자 요청과 결정. `CLAUDE.md` 규칙, `/say-my-day-design` 스킬 절차(화면을 만질 때)

## 결정 (사용자 승인)
- 방식: 브라우저 인쇄 기능("PDF로 저장") + 인쇄 전용 스타일. 라이브러리·서버 없음(비용 0, CJK 글꼴 안전). 직접 PDF 생성은 하지 않는다.
- 위치: 보관함의 단어/문장 탭 위쪽 버튼. 누르면 현재 탭의 목록.
- 범위: **지금 배우는 언어 조합만**(`inScope`, `loadWords`/`loadSents`).
- 내용: 단어 = 단어·읽기(병음/히라가나)·뜻·**예문(넣기)**, 문장 = 문장·읽기·뜻. 저장 순서.
- 시험지(뜻 가림) 모드: **지금은 만들지 않고 나중에 추가**. 구조만 확장 가능하게.
- CSV: **지금은 만들지 않는다**(PDF만).

## 할 일
1. 인쇄용 영역(화면에는 숨김, `@media print`에서만 보임) + 현재 탭 목록으로 채우기. 제목에 언어 조합·날짜·개수.
2. 보관함 버튼 + 항목이 없을 때 비활성/안내. 새 문구는 `L()`/`ZH`에 중국어까지.
3. 인쇄 후 화면 복원, 다크 모드에서도 인쇄는 흰 바탕·검은 글자.

## 반드시 유지할 기능
F9(저장·내보내기: 기존 JSON 백업은 그대로), 보관함·복습 동작.

## 완료 기준·검증
인쇄 미디어 에뮬레이션 스크린샷(ko>zh, ko>ja, zh>ja), 항목 0개·많은 개수(페이지 넘김) 확인, `npm test` 통과. 실기기에서 "PDF로 저장"은 사용자 확인.
공통: 백업 먼저(`backup/index_<이름>_v48~`), 분리 서버로만 시험, 사용자 확인 항목은 "미확인"으로 기록.
