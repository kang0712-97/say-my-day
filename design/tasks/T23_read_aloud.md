# T23 따라 읽기·음성·글자 강조
상태: 완료(미확인: 휴대폰 화면·실제 소리·글자 강조 체감, 중국어 문구)
근거: `design/redesign-plan.md`(읽고 시작), `/say-my-day-design` 스킬 절차, DESIGN.md '기능별 화면 > 따라 읽기', 보드 03(오른쪽), `design/tasks/T2`·`T3`·`T13`

## 할 일
1. 따라 읽기 화면: 선택한 문장, 발음 표기, 원문, 현재 순서(n/m), 이전·재생(72px)·다음, '전체 듣기', 속도·문장 간격·병음/후리가나 표시·원문 표시 조절. 녹음·채점은 만들지 않는다. 새는 기본 생략(최대 56px 선택).
2. 소리 경로 유지: 신경망 음성(`speakWhole`/`speakSegment`) → 실패 시 기기 음성 폴백(`edgeDown`), 음성 없음 안내, 재생 중 다른 화면 이동 시 정지.
3. 글자 강조(`karBegin`, `charTimes`)를 새 읽기 구조(T20)와 새 색(밝은 면+잉크)으로 유지, 강조를 색만으로 하지 않는다(배경+밑줄 병행).

## 반드시 유지할 기능 (기능 확인표 번호는 계획서 §4)
F4·F5. 속도·간격 설정 저장, 통독 순서, 일본어 전용 보정(히라가나 합성 치환, T3).

## 완료 기준
- 이전·재생·다음·전체 듣기·속도·간격·표시 토글이 모두 동작하고 새로고침 후 설정 유지.
- 신경망 음성 실패(`EDGE_TTS_ENABLED=0`) 때 기기 음성으로 이어지고 안내 표시.
- 글자 강조가 소리와 어긋나지 않음(`tests/char_times_check.js`, `tests/ja/tts_offset_check.py`).
- 재생 버튼 72px, 조작 44px 이상.

## 검증 방법
`npm test` 통과(분리 서버), 라이트·다크 × ko>zh·ko>ja·zh>ja × 폭 360/390 스크린샷을 해당 보드와 나란히 비교, 글자 200% 가로 넘침 0, 사용한 색 쌍을 `contrast-check`로 재계산. 소리·실기기는 "미확인"으로 적고 사용자에게 요청.
추가: 실제 소리·강조 체감은 사용자 귀·눈 확인(미확인). 폴백은 분리 서버에서 환경변수로 재현.

## 결과
따라 읽기 화면을 새 구조로 바꿨다(소리·강조 코드는 그대로). 백업 `backup/index_read_v38.html`.
- 문장 카드: 둥근 면 카드, 지금 읽는 문장은 옅은 회색 면+잉크 테두리+왼쪽 막대(색만으로 알리지 않음). 글자는 색이 차오르고 지금 읽는 글자에 밑줄(`.c.now`)을 함께 둔다.
- 하단 조작: 이전·다음 44px, 재생 72px 원형(글자 "전체 듣기/이어 듣기/일시정지" 포함, aria-label 동기화), 'n / m', 속도·문장 간격 선택, 병음(후리가나)·원문 체크(모두 44px). 제목 "따라 읽기"(중국어 "跟读"), 새는 생략.
- 확인(분리 서버, 실제 크롬, ko>zh 다크·ko>ja 라이트/다크·zh>ja): 재생 72×72, 이전·다음 44×44, 선택·체크 44, 설정(속도·간격·원문) 닫았다 열어도 유지, 이전/다음 'n / m' 갱신, 재생 시 신경망 음성에서 글자 채움·밑줄 동작·오류 없음. `EDGE_TTS_ENABLED=0`이면 기기 음성(Google 日本語)으로 재생. 글자 200%에서 가로 넘침 0. `node tests/char_times_check.js` 전부 일치. `npm test` 전부 통과.

- 미확인: 휴대폰 화면, 실제 소리와 글자 강조의 어긋남 체감(`tests/ja/tts_offset_check.py`는 타이밍 코드를 바꾸지 않아 다시 돌리지 않음), 중국어 문구 1개("跟读").
- 하지 않은 것: 따라 읽기 화면 안의 "선택 문장 하나만 크게" 보기(전체 문장 목록 유지), 새 이미지.
