# 디자인 시험 (피드백: "기존 UI/UX가 별로다")
기본 화면은 그대로 두고, 레퍼런스 5장에서 뽑은 **화면 구성이 다른 3안**을 겹쳐 입혔다. 기능·문구는 같다(마크업은 그대로, 배치는 CSS 격자로 바꿈).

| 안 | 주소 | 참고 | 구성 |
|---|---|---|---|
| base | `?skin=base` | (현재) | |
| index | `?skin=index` | IABR 목록, Booking·Receipt | 표처럼 줄 맞춘 행(언어·날짜·질문·쓰기·개수/번역 줄). 결과는 2열 카드 격자(글자를 키우면 1열), 이동 메뉴는 3×2 표. 하단 메뉴는 글자만. 주황 정사각 화살표 버튼 |
| player | `?skin=player` | 주황 오디오 앱 | 쓰기는 흰 카드 하나(입력창+예시 2×2 버튼+넓은 번역 버튼). 결과는 위에 붙는 재생 막대(목록/한 문장씩/전체 읽기)와 "한 문장 = 한 카드"(원문 상자, 듣기 넓은 버튼, 복사·저장 반반) |
| notes | `?skin=notes` | Nothing 설정, Fokus | 쓰기는 종이 한 장(커서 깜박이는 제목, 테두리 없는 큰 입력, 아래 도구줄에 개수+검은 원형 번역 버튼). 결과는 폴더 목록 같은 줄 나열, 이동은 밑줄 탭. 일기장은 월 제목·테두리 날짜 |

사용법: 주소 뒤에 `?skin=index` 처럼 붙여 열면 그 안으로 보이고, 왼쪽 위에 선택기(base/index/player/notes)가 나타나 바꿔 볼 수 있다. 선택은 그 브라우저에 기억된다.
끝내기: `index.html`의 `skins.js`·`skins.css` 두 줄과 `app/public/skins.*` 삭제.
다크 모드: 색은 기본 다크, 배치·글꼴만 안을 따른다.
시험: `SKIN=index node tests/smoke/run.js`, `SKIN=index node tests/a11y/run.js` (세 안 모두 통과). 색 대비는 라이트 기준 4.5:1 이상.
미확인: 실제 휴대폰, 중국어 UI(zh) 화면에서의 모양, 폰트 불러오기 속도, 일기장·보관함·설정 시트의 안별 모양(notes의 일기장만 손봄), 퀴즈 화면의 안별 배치(색·모서리만 바뀜).
