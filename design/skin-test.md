# 디자인 스킨 시험 (피드백: "기존 UI/UX가 별로다")
기본 화면은 그대로 두고, 레퍼런스 5장에서 뽑은 스타일 3가지를 겹쳐 입혀 비교한다. 기능·문구는 같고 색·글꼴·모양만 다르다.

| 스킨 | 주소 | 참고한 레퍼런스 | 특징 |
|---|---|---|---|
| base | `?skin=base` | (현재) | 크림 종이·세리프·붉은 포인트 |
| line | `?skin=line` | IABR 목록, Booking·Receipt | 가는 검은 선 격자, 알약 윤곽, 얇은 산세리프, 주황 포인트, 정사각 주황 화살표 버튼 |
| mono | `?skin=mono` | Nothing 설정 화면, Fokus | 고정폭·도트 글꼴, 크림 종이, 사각 검정 윤곽, 대문자 라벨 |
| soft | `?skin=soft` | 오디오 앱(주황 카드) | 흰 카드·큰 둥근 모서리·부드러운 그림자, 주황 포인트 |

사용법: 앱 주소 뒤에 `?skin=line` 처럼 붙여 열면 그 스킨으로 보이고, 화면 왼쪽 위에 작은 선택기(base/line/mono/soft)가 나타나 바로 바꿔 볼 수 있다. 선택은 그 브라우저에 기억된다.
되돌리기/끝내기: 선택기에서 base, 시험이 끝나면 `index.html`의 `skins.js`·`skins.css` 두 줄과 `app/public/skins.*` 파일을 지운다.
다크 모드: 색은 기본 다크를 그대로 쓰고 글꼴·모양만 스킨을 따른다(스킨별 다크 색은 아직 없음).
시험: `SKIN=line node tests/smoke/run.js` / `SKIN=line node tests/a11y/run.js` (line·mono·soft 모두 통과). 글자색 대비는 라이트 기준 전부 4.5:1 이상.
미확인: 실제 휴대폰 화면, 일본어·중국어 UI(zh) 화면에서의 모양, 폰트가 인터넷에서 불러와지는 속도(Google Fonts).
