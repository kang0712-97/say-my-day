# 독립감수 1회 기록 (2026-10-14)

대상: 프롬프트 v0.3, 화면 v1, `tests/real_01.json`. 감수자는 파일을 읽기만 했다.

## 중국어 교사 관점 (핵심)
- 한국어 원문이 `자격증`→`자격证`으로 바뀌어 표시됨. 감수자는 사용자 오타로 봤으나 실제로는 모델이 원문을 되풀이하다 바꾼 것(앱 버그).
- `沉浸`, `编程`이 초급 수준을 넘고, note가 "쉽게 썼다"고 말해 모순.
- 하나 번역의 호감 어감 약화, `幸福` 어감 note 없음.
- 단어 선택이 너무 쉬운 단어 위주(听, 好吃), 일기 핵심어 누락.
- 발음 팁 중복, `醒` 설명에 ㅅ·ㅎ 혼합 비유.
- 병음 라이브러리의 경성·得 오류 가능성 (점검 결과 `过得`→dé 등 실제 오류 확인).

## UX 관점 (핵심)
- 20~30초 대기 중 피드백 부족, 오류 문구가 원문 그대로 노출.
- 결과 저장·복습 없음, 병음/한국어 토글 없음.
- 듣기: alert 사용, 중국어 음성 없을 때 한국어로 읽을 위험, 정지·속도 조절 없음.
- 긴 결과 탐색 어려움, 모바일 표 죽은 CSS, 병음 크기·대비, 듣기 버튼 접근성 이름 동일.
