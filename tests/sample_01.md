# 테스트 01 (2026-10-14)

> 주의: API 키 없이 Claude(Code 세션)가 프롬프트 v0.1 규칙대로 직접 만든 시뮬레이션 결과다. 실제 앱의 API 출력과 같다는 보장은 없다. 병음은 앱에서 pinyin-pro로 생성할 예정이라 아래 병음은 사람이 읽기 위한 참고용이며 라이브러리와 대조가 필요하다.

## 입력
오늘은 아침에 빗소리를 들으며 깼다. 기분 좋은 시작이다. AI교육에서 프로그램으로 다람쥐 게임을 만들어봤다. 해볼 수 있는 게 많아져서 재밌다. 이거에도 몰입하고 싶은데 취업이 가장 중요하고 자격증 시험 준비도 해야 된다. 할게 많다. 그래도 밥은 맛있고, 하나는 좋다. 행복하게 보냈다.

## 문장별 번역

| # | 한국어 | 간체 | 병음(참고) |
|---|---|---|---|
| 1 | 오늘은 아침에 빗소리를 들으며 깼다. | 今天早上我听着雨声醒来了。 | Jīntiān zǎoshang wǒ tīngzhe yǔshēng xǐnglái le. |
| 2 | 기분 좋은 시작이다. | 心情很好，是个好的开始。 | Xīnqíng hěn hǎo, shì ge hǎo de kāishǐ. |
| 3 | AI교육에서 프로그램으로 다람쥐 게임을 만들어봤다. | 在AI课上，我用程序做了一个松鼠游戏。 | Zài AI kè shang, wǒ yòng chéngxù zuòle yí ge sōngshǔ yóuxì. |
| 4 | 해볼 수 있는 게 많아져서 재밌다. | 能做的事变多了，很有意思。 | Néng zuò de shì biàn duō le, hěn yǒu yìsi. |
| 5 | 이거에도 몰입하고 싶은데 취업이 가장 중요하고 자격증 시험 준비도 해야 된다. | 我也想专心做这个，可是找工作最重要，还要准备资格证考试。 | Wǒ yě xiǎng zhuānxīn zuò zhège, kěshì zhǎo gōngzuò zuì zhòngyào, hái yào zhǔnbèi zīgézhèng kǎoshì. |
| 6 | 할게 많다. | 要做的事很多。 | Yào zuò de shì hěn duō. |
| 7 | 그래도 밥은 맛있고, 하나는 좋다. | 不过饭很好吃，我也喜欢小花。 | Búguò fàn hěn hǎochī, wǒ yě xǐhuan Wūdōng. |
| 8 | 행복하게 보냈다. | 我过得很幸福。 | Wǒ guò de hěn xìngfú. |

**설계 기준에 따른 판단**
- 문장 5는 한국어 한 문장이 길어 중국어도 길어진다(27자). 규칙 3(20자 이내)과 충돌하므로 앱에서는 "두 문장으로 나눠 보기"가 필요하다. 프롬프트 수정 후보.
- 문장 3의 `다람쥐`는 정확히는 `花栗鼠(huāchǔshǔ)`지만, 초급에서는 `松鼠(sōngshǔ, 청설모·다람쥐 통칭)`가 더 쉽고 자주 쓰여 이쪽을 택했다. `note`에 이유를 남겨야 한다.
- 문장 7의 `하나`는 이름(반려동물·사람)인지 음식(하나)인지 모호하다. 위 번역은 음식 `小花`로 가정했다. 프롬프트 규칙 6에 따라 `ambiguities`에 올라와야 하는 사례다. **강님 확인 필요: 하나가 누구/무엇인가요?**
- 문장 1의 `깼다`는 `醒来了`로 옮겼다. `起床(일어나다)`와 다르다는 점을 해설에 넣을 만하다.

## 단어 (vocab)

| 중국어 | 병음 | 뜻 | 급수 |
|---|---|---|---|
| 醒来 | xǐnglái | 잠에서 깨다 | HSK 4 이상 추정, 확인 필요 |
| 心情 | xīnqíng | 기분 | HSK 3 |
| 开始 | kāishǐ | 시작 | HSK 2 |
| 有意思 | yǒu yìsi | 재미있다 | HSK 3 |
| 重要 | zhòngyào | 중요하다 | HSK 3 |
| 准备 | zhǔnbèi | 준비하다 | HSK 3 |
| 找工作 | zhǎo gōngzuò | 취업하다·직장을 구하다 | HSK 2+3 조합 |
| 幸福 | xìngfú | 행복하다 | HSK 4 추정, 확인 필요 |

HSK 급수는 모델이 틀리기 쉬운 항목이다. 앱에서는 급수 표기를 빼거나 공식 어휘표로 대조해야 한다.

## 문법 (grammar)
1. **V + 着 (동작이 지속되는 상태)**: `听着雨声醒来` = 빗소리를 들으며 깨다. 동사 뒤에 着를 붙여 "~하면서"의 느낌을 만든다.
2. **变 + 形容词 + 了 (변화)**: `变多了` = 많아졌다. 상태가 바뀐 것을 `了`로 표시한다.
3. **虽然/可是 계열 접속**: `可是找工作最重要` = 그런데 취업이 가장 중요하다. 앞 내용을 받아 반대되는 사정을 말한다.

## 발음 팁 (예시)
- `心情 xīnqíng`: `q`는 한국어 ㅊ보다 혀를 앞으로 대고 바람을 세게 낸다.
- `是个 shì ge`: `个`는 경성이라 짧고 가볍게 읽는다.
- `重要 zhòngyào`: 4성 + 4성 연속이므로 두 번째를 더 약하게 떨어뜨린다.

## 활용 문장 (extra_sentences)
- 비 오는 날 기분을 말할 때: 下雨天我心情很平静。(Xià yǔ tiān wǒ xīnqíng hěn píngjìng.)
- 할 일이 많다고 말할 때: 最近事情太多了，有点累。(Zuìjìn shìqing tài duō le, yǒudiǎn lèi.)
- 좋아하는 음식을 말할 때: 今天的晚饭特别好吃。(Jīntiān de wǎnfàn tèbié hǎochī.)
- 하루를 마무리할 때: 今天过得很开心。(Jīntiān guò de hěn kāixīn.)
